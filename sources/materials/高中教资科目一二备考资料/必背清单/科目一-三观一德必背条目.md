# 必背清单 ①｜科目一"三观一德"必背条目（**42 分材料分析的命根子**）

> 用法：三轮复习每轮默写一遍。**加粗**＝阅卷找的"关键词"，必须原样出现在答案里。

---

## 一、教育观（素质教育）——6 条 + 材料对应

| 条目 | 必背表述 | 材料中出现即判"符合" |
|---|---|---|
| ① **提高国民素质为根本宗旨** | 教育要面向**全体学生**，为每一位学生的发展负责 | 教师不放弃"后进生"、面向全班设计活动 |
| ② **面向全体学生** | 把学习的主动权交给学生、**面向每一位学生**（不是少数尖子） | 分层提问、人人有岗位、公开成绩不排名 |
| ③ **促进学生全面发展** | **德智体美劳**全面和谐发展，克服"唯分数、唯升学" | 组织体育、美育、劳动与社团活动 |
| ④ **促进学生个性发展** | 承认差异、发展特长，"**一把钥匙开一把锁**" | 发现学生兴趣并为其搭建平台 |
| ⑤ **以培养创新精神和实践能力为重点** | 创新是**素质教育的时代特征**（最根本的特征） | 让学生动手实验、探究、质疑、做项目 |
| ⑥ **促进学生创新精神**（同上合并） | 从"以教育者为中心"转向"**以学习者为中心**"；从"教会学生知识"转向"**教会学生学习**"；从"**重结论轻过程**"转向"**重结论的同时更重过程**"；从"**关注学科**"转向"**关注人**" | 教师引导自主探究、重视过程性评价 |

**新课的教学观四对**（材料分析万能句）：**教学从"教育者为中心"转向"学习者为中心"；从"教会学生知识"转向"教会学生学习"；从"重结论轻过程"转向"重结论的同时更重过程"；从"关注学科"转向"关注人"。**

---

## 二、学生观（"**两独一发展**"）——3 条 + 反例

| 条目 | 必背表述 | 常用材料场景 |
|---|---|---|
| ① **学生是发展的人** | 学生具有**巨大的发展潜能**；学生是**处于发展过程中**的人，有不足是难免的，应用**发展的眼光**看学生；学生的身心发展**有规律** | 学生犯错、成绩暂时落后，教师耐心引导、"不翻旧账" |
| ② **学生是独特的人** | 学生是**完整的人**（不是学习机器）；学生有**自身的独特性**（兴趣、气质、经验不同）；学生与成人之间存在着**巨大的差异** | 因材施教、发现特长、尊重个性 |
| ③ **学生是具有独立意义的人** | 每个学生都是**独立于教师头脑之外，不以教师的意志为转移的客观存在**；学生是**学习的主体**；学生是**责权的主体** | 教师强制、包办代替、不让学生参与决策 |

**教师应怎么做（万能收尾）**：尊重学生人格与个体差异；把学生看作发展的、有潜能的人；发挥学生主体性，引导自主、合作、探究；面向全体、因材施用；建立**民主、平等、和谐**的师生关系。

## 三、教师观——角色转变 4 条 + 行为转变 2 条

**① 教师角色的转变**
- 从知识的传授者转变为学生学习的**引导者和发展的促进者**（**最具有个体意义/核心**的角色转变）；
- 从"教书匠"转变为教育教学研究的**反思者、研究者**；
- 从课程的执行者转变为课程的**建设者和开发者**；
- 从"校长的打工者/关门办学"转变为**社区型开放教师**、家校社协同的教育者；
- 教师是**学生的榜样（示范者）、朋友（心理辅导者）、管理者与组织者**。

**② 教师教学行为的转变**
- 在对待师生关系上，强调**尊重、欣赏**（"没有尊重就没有教育"）；
- 在对待教学上，强调**帮助、点拨、引导**（不是替代）；
- 在对待自我上，强调**反思**（"**经验 + 反思 = 成长**"，波斯纳）；
- 在对待同事关系上，强调**合作**（教师集体、协同育人）。

**③ 教师职业劳动特征**（也常在材料中出现）：复杂性、创造性（**因材施教、教学有法无定法、教育机智**）、连续性、广延性、长期性、间接性、主体性、示范性、劳动成果的综合性。

## 四、教师职业道德规范（2008 年修订，"**三爱两人一终身**"）

| 条目 | 内涵必背（关键词） | 常见材料 |
|---|---|---|
| **爱国守法**（基本要求） | 热爱祖国，拥护党的领导，**全面贯彻国家教育方针**，**自觉遵守教育法律法规**，**依法履行教师职责权利**，**不得有违背党和国家方针政策的言行** | 体罚、违规补课、宣传不当言行→违背 |
| **爱岗敬业**（本质要求） | **忠诚于人民教育事业**，志存高远，勤恳敬业，**甘为人梯，乐于奉献**；**对工作高度负责**，**认真备课上课，认真批改作业，认真辅导学生**，**不得敷衍塞责** | 备课马虎、作业长期不改→违背 |
| **关爱学生**（师德的灵魂） | 关心**全体学生**，尊重学生**人格**，**平等公正**对待学生；**对学生严慈相济，做学生良师益友**；**保护学生安全，关心学生健康，维护学生权益**；**不讽刺、挖苦、歧视学生，不体罚或变相体罚学生** | 罚抄 100 遍、当众羞辱、只关心尖子→违背 |
| **教书育人**（教师天职/道德的核心） | 遵循**教育规律**，实施**素质教育**；**循循善诱，诲人不倦，因材施教**；培养学生**良好品行**，激发学生**创新精神**，促进学生**全面发展**；**不以分数作为评价学生的唯一标准** | 只抓分数、放弃德育→违背 |
| **为人师表**（内在要求） | 关心集体，**团结协作**，尊重同事，尊重家长；**作风正派，廉洁奉公**；**自觉抵制有偿家教，不利用职务之便谋取私利**；**衣着得体，语言规范，举止文明** | 收礼、有偿家教、出言不逊→违背 |
| **终身学习**（发展的不竭动力） | 崇尚**科学精神**，**严谨治学**；**自主发展**，**拓宽知识视野**，**更新知识结构**；**潜心研究业务，不断改进教学方法**，**不断提高专业素养和教育教学水平** | 拒绝教研、照本宣科→违背 |

**答题模板（14 分）**
```
①总判断：×老师的做法是（不）符合中小学教师职业道德规范的，值得（不）赞同。
②分条作答（一般答 3—4 条即可）：
   【规范名】+ 规范内容（材料中体现该要求的具体表述）+ 结合材料（引原句/概括）+ 结论（该教师做到了/没有做到这一点）。
③总结：作为新时代教师，应以此为镜，坚持立德树人，把师德规范落实到教育教学全过程。
```

## 五、"三观一德"最容易失分的 8 处

1. 只写"素质教育"却不写**六条要点**（阅卷按条给分）；
2. 学生观漏掉"**独立意义的人 = 客观存在 + 学习主体 + 责权主体**"三层；
3. 教师观写成"教师要当演员/导演"这类**非标准表述**；
4. 把"**关爱学生**"写成"**热爱学生**"（规范原文是"关爱学生"）；
5. 抄材料不分析，或分析脱离规范关键词；
6. 判断句缺失（未先说"符合/不符合"）；
7. 只答"尊重学生"却漏"**平等公正、不讽刺挖苦歧视、不体罚或变相体罚**"；
8. 结尾无"应如何做"，缺少价值立场（立德树人）。
