# 科目一 02 · 教育法律法规

**考向**：单选 5—12 题（16 分，占卷面 10%）；同时为材料分析题、作文提供"依法执教"的价值底色。
**特点**：本模块是科目一客观题里**失分率最高**的一块——因为干扰项都改得很细。
**策略**：**先通读原文（见《法律法规与政策文件通读清单.md》第一梯队），再做本表的"改写陷阱"对照**。

## 一、法律关系与法律救济（先建立框架）

```
教育法律关系 = 主体（自然人/机构/国家机关） + 内容（权利与义务） + 客体（物、行为、精神产品、人身利益）
法律责任 = 民事责任（赔偿、赔礼道歉、恢复原状…）
         + 行政责任（行政处分：警告→记过→记大过→降级→撤职→开除；行政处罚：警告、罚款、没收、吊销许可证、行政拘留…）
         + 刑事责任（主刑：管制、拘役、有期徒刑、无期徒刑、死刑；附加刑：罚金、剥夺政治权利、没收财产、驱逐出境）
法律救济途径：教师申诉、学生申诉、行政复议、行政诉讼、民事诉讼、调解、仲裁
```

**"处分"给内部人员（公职人员），"处罚"给外部相对人**——单选题最爱挖的坑。
判断口诀：**"行政机关对外 = 处罚；机关/学校对内 = 处分。"**

## 二、教师：权利、义务、禁止行为（教师法必背）

### 教师法第 7 条｜六项权利（记："教学、研究、指导学生、拿工资、民主管理、进修"）
| 权利 | 常见侵权情形（选择题会给你案例） |
| --- | --- |
| ① 教育教学权（进行教育教学活动，开展教育教学改革和实验） | 学校无正当理由不让其上课、频繁调离教学岗 |
| ② 科学研究权（从事科学研究、学术交流，参加专业学术团体） | 不许参加学术会议、扣发论文奖励 |
| ③ 指导评价权（指导学生学习和发展，**评定品行和学业成绩**） | 校方直接改动教师给出的评语/成绩 |
| ④ 获取报酬待遇权（按时获取工资报酬，享受国家规定的福利待遇以及寒暑假期的带薪休假） | 拖欠工资、克扣绩效、不缴社保、寒暑假安排无薪值班 |
| ⑤ 民主管理权（对学校教育教学、管理工作和教育行政部门的工作提出意见和建议，通过教职工代表大会等形式参与民主管理） | 不开教代会、否决提案 |
| ⑥ 进修培训权（参加进修或者其他方式的培训） | 拒绝公派培训、培训扣工资 |

### 教师法第 8 条｜六项义务
① 遵守宪法、法律和职业道德，为人师表；② 贯彻国家的教育方针，遵守规章制度，执行学校教学计划，**履行教师聘约，完成教育教学工作任务**；③ 对学生进行宪法所确定的基本原则的教育和爱国主义、民族团结教育、法制教育以及思想品德、文化、科学技术教育，组织、带领学生开展有益的社会活动；④ **关心、爱护全体学生，尊重学生人格，促进学生在品德、智力、体质等方面全面发展**；⑤ **制止有害于学生的行为或者其他侵犯学生合法权益的行为，批评和抵制有害于学生健康成长的现象**；⑥ 不断提高思想政治觉悟和教育教学业务水平。

### 资格与限制
| 事项 | 规定 |
| --- | --- |
| 学历要求（第 11 条） | 幼儿园：幼儿师范毕业及以上；小学：中等师范毕业及以上；**初中：高等师范专科或其他大学专科及以上**；**高中/中职文化课：高等师范院校本科或其他大学本科及以上**；中职实习指导：中职毕业及以上并具备助理工程师以上专业技术职务或中级以上工人技术等级 |
| 丧失资格（第 14 条） | **受到剥夺政治权利**或者**故意犯罪受到有期徒刑以上刑事处罚**的，不能取得教师资格；已取得者丧失教师资格 |
| 撤销资格（《教师资格条例》） | 弄虚作假、骗取教师资格的；品行不良、侮辱学生，影响恶劣的 → **自撤销之日起 5 年内不得重新申请认定** |
| 行政处分或解聘（第 37 条） | ① **故意不完成教育教学任务**给教育教学工作造成损失；② **体罚学生，经教育不改**；③ **品行不良、侮辱学生，影响恶劣** |
| 申诉（第 39 条） | 教师对学校侵犯其合法权益或不服处理，可向教育行政部门申诉；教育行政部门应当**自接到申诉之日起 30 日内**作出处理 |
| 平均工资（第 25 条 / 义务教育法第 31 条） | 教师的平均工资水平应当**不低于或者高于**国家公务员的平均工资水平（义务教育法表述为"不低于当地公务员的平均工资水平"） |

## 三、学生：核心权利与对应侵权判断

| 权利 | 侵权案例（题干常见） |
| --- | --- |
| **受教育权**（最重要、学生专属） | 停课罚站一节课以上、赶出教室、劝退、开除（义务教育阶段）、不让参加考试、占用课程、没收课外书且不还 |
| **人身权—生命健康权** | 体罚致伤、让学生做超量运动、校舍隐患、组织抢险救灾 |
| **人身权—人格尊严权** | 罚抄"我是笨蛋"、起侮辱性绰号、当众宣读成绩并讽刺、扇耳光（身体+人格） |
| **人身权—身体权/人身自由权** | 关"小黑屋"、搜身、放学后长时间留堂不让走、课间不许出教室 |
| **财产权** | 没收手机不还、罚款、撕坏学生书本不赔、让学生买指定教辅 |
| **隐私权** | 公开成绩与名次、拆看信件日记、公布家庭情况、公开心理测评结果 |
| **肖像权、名誉权、荣誉权** | 未经同意把学生照片用于招生广告、非法撤销已授予的荣誉称号 |
| **休息权** | 占用节假日集体补课、拖堂、要求提前到校 |
| **申诉权、参与权** | 处分不听取陈述申辩、不组织听证 |

> 高频判断：**"罚抄 20 遍"若超出正常限度 → 变相体罚**；**"一节课内教室内站立"→ 合法的一般教育惩戒**（惩戒规则第 8 条）。
> **公开成绩排名 → 违规**（未成年人学校保护规定第 10 条），但**告知本人和家长 → 合法且应当便利**。

## 四、责任主体判断表（"该谁担责"三步法）

**第一步：看行为主体是谁**（学生本人 / 教师职务行为 / 学校管理瑕疵 / 校外第三人 / 监护人）
**第二步：看学生年龄**（不满 8＝无民事行为能力人；8—18＝限制民事行为能力人；16 以上以自己劳动收入为主要生活来源＝视为完全）
**第三步：看过错与因果关系**

| 场景 | 归责方式 | 依据 |
| --- | --- | --- |
| **无民事行为能力人**（不满 8 岁）在校受人身损害 | 学校承担**过错推定**责任（学校须自证尽职） | 民法典第 1199 条 |
| **限制民事行为能力人**（8 岁以上，中学生基本在此）在校受人身损害 | **过错责任**：受害人一方须证明学校未尽教育、管理职责 | 民法典第 1200 条 |
| 校外**第三人**侵权造成学生损害 | 第三人担责；学校未尽管理职责的承担**相应的补充责任**，可向第三人追偿 | 民法典第 1201 条 |
| 教师在**履行职务**中致学生损害 | 由**学校**承担责任（学校可再向有故意或重大过失的教师追偿）；处理教师依教师法第 37 条 | 教育法、伤害事故办法 |
| 学生**特异体质未告知**、自杀自伤、突发不可抗力、对抗性体育竞赛意外 | 学校行为并无不当的，**不承担责任** | 学生伤害事故处理办法第 10、12 条 |
| 学校组织抢险救灾导致学生受伤 | 学校有过错（不得组织学生参加抢险救灾） | 未成年人学校保护规定第 7 条 |

## 六、五类高频"改写陷阱"（做错就回原文）

| 陷阱类型 | 错误示例 | 正确表述 |
| --- | --- | --- |
| 程度副词 | "学校**可以**平等对待学生" | "**应当**" |
| 主体错位 | "**学校**批准免予入学" | "**乡镇人民政府或县级教育行政部门**" |
| 数字偷换 | "10 个工作日内申诉" | "**15 个工作日**" |
| 程序颠倒 | "先处分，后告知家长" | 严重惩戒**应当事先告知家长**；较重惩戒**应当及时告知家长** |
| 张冠李戴 | "《义务教育法》规定教师工资不低于公务员" | **两法都有**，但表述主体与措辞不同；《教师法》为"不低于或者高于国家公务员的平均工资水平" |

## 七、真题风格自测

1. 高一学生甲（16 岁）在体育课上与同学乙打闹致乙门牙断裂。经查，体育老师丙当时在操场另一端接电话，未及时发现制止。下列说法正确的是（ ）。
   A. 由丙老师个人赔偿 B. 由学校承担全部赔偿责任 C. 由甲的监护人承担主要责任，学校未尽管理职责承担相应责任 D. 由乙自行承担
2. 依据《中小学教育惩戒规则（试行）》，教师可以当场实施的是（ ）。
   A. 一节课内教室内站立 B. 不超过一周的停课 C. 警告处分 D. 承担校内公益服务任务
3. 某初级中学为提升升学率，将九年级按成绩分为 A、B 两层班，并公开张榜公布每次月考名次。依据相关法律，该做法（ ）。
   A. 合法，属学校办学自主权 B. 违法，分设重点班且公开成绩名次 C. 仅公开名次违法 D. 仅分设重点班违法
4. 教师资格丧失的法定情形是（ ）。
   A. 受到行政拘留处罚 B. 受到剥夺政治权利 C. 年度考核不合格 D. 体罚学生被通报批评
5. 依据《新时代中小学教师职业行为十项准则》，属于"关心爱护学生"要求的是（ ）。
   A. 不得在教育教学活动中遇突发事件、面临危险时，不顾学生安危，擅离职守
   B. 不得与学生发生任何不正当关系，严禁任何形式的猥亵、性骚扰行为
   C. 不得在招生、考试、推优、保送及绩效考核、岗位聘用、职称评聘、评优评奖等工作中徇私舞弊、弄虚作假
   D. 不得抄袭剽窃、篡改侵吞他人学术成果

<details>
<summary>参考答案与解析</summary>

1. **C**。限制民事行为能力人在校受害适用过错责任；直接侵权人是甲（其监护人承担民事责任），学校因教师未及时制止存在管理过错，承担相应责任；丙在履行职务中，不对外个人赔偿。
2. **A**。B、D 属学校实施的第 10、9 条措施；C 是纪律处分。
3. **B**。义务教育学校不得分设重点班和非重点班（义教法第 22 条），且考试成绩、名次不得公开（未成年人学校保护规定第 10 条）。
4. **B**。第 14 条：剥夺政治权利或故意犯罪受有期徒刑以上刑事处罚。
5. **B**。A 属"加强安全防范"，C 属"遵循公平原则"，D 属"秉持诚实正直"。
</details>
