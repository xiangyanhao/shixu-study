# 科目一 01 · 职业理念（教育观 / 学生观 / 教师观）

**考向**：单选 1—4 题（8 分）+ 材料分析题第 30 题（14 分）= **约 22 分，占卷面 15%**
**背诵优先级**：★★★★★（本模块是全卷性价比最高的 22 分，背 3 天就能拿 18 分以上）

---

## 一、素质教育观（教育观）

### 1. 素质教育的内涵（5 条，必须一字不差）
1. 素质教育是**面向全体学生**的教育（不是只面向少数优等生；对应"教育机会均等"）
2. 素质教育是**促进学生全面发展**的教育（德智体美劳"五育"并举，不是只抓智育）
3. 素质教育是**促进学生个性发展**的教育（承认差异、因材施教，不是"一刀切"）
4. 素质教育以**培养学生的创新精神和实践能力为重点**（时代特征，是素质教育的**灵魂**）
5. 素质教育是**以提高国民素质为根本宗旨**的教育（战略意义）

### 2. 素质教育与"三个面向""四有""五育"
- 邓小平：**教育要面向现代化、面向世界、面向未来**
- 教育方针（《教育法》2021 修正第 5 条 / 新时代党的教育方针）：教育必须为社会主义现代化建设服务、**为人民服务**，必须与**生产劳动和社会实践相结合**，培养**德智体美劳**全面发展的社会主义建设者和接班人。
- 立德树人是教育的**根本任务**；"三全育人"＝全员、全过程、全方位育人。
- 五育关系：德育（灵魂/动力）、智育（前提/支持）、体育（基础/物质前提）、美育（动力/熏陶）、劳动技术教育（综合载体）——相互依存、不可相互替代。**"没有分离的不完整教育，也没有独立存在的某育。"**

### 3. 新课改背景下教学观的转变（4 组）
| 从 | 转变为 |
| --- | --- |
| 课程执行者 | 教学是**课程创生与开发**的过程 |
| 单向传授 | 教学是**师生交往、积极互动、共同发展**的过程 |
| 重结果 | **重过程**（知识与技能、过程与方法、情感态度价值观三维目标 → 核心素养） |
| 重学科 | **关注人**（关注学生的情绪、情感与道德生活） |

### 4. 学习方式
自主、合作、探究是新课改倡导的学习方式。**合作学习的有效条件**：明确的共同目标、异质分组（组间同质、组内异质）、个人责任与小组责任、社交技能培训、教师巡视与适时介入、小组自评。
> 易错：不是所有课都要"合作探究"；**接受学习与发现学习、自主与合作没有绝对的优劣，关键看条件与目的**（这条既出科目一单选，也出科目二辨析）。

### 5. 实施素质教育的途径
① 主渠道＝**课堂教学**；② 建设全面和谐的课程体系；③ 改进教学方法与评价方式（发展性评价、多元评价）；④ 课外活动与社会实践；⑤ 营造校园文化；⑥ 建设高素质教师队伍；⑦ 推进教育管理体制与招生考试制度改革。

## 二、学生观（"以人为本"的学生观）

### 三大要点（背诵顺序：发展—独特—独立意义）

**1. 学生是发展的人**
- 学生的身心发展**是有规律的**（顺序性、阶段性、不平衡性、互补性、个别差异性）
- 学生具有**巨大的发展潜能**（可用"皮格马利翁效应/罗森塔尔效应"佐证）
- 学生是**处于发展过程中**的人，犯错是成长的正常代价，不能求全责备

**2. 学生是独特的人**
- 学生是**完整的人**（不是"学习机器"，不能只以成绩评价）
- 学生有**自身的独特性**（兴趣、智能结构、风格不同 → 因材施教）
- 学生与**成人之间存在巨大差异**（不能用成人标准衡量，"儿童不是小大人"）

**3. 学生是具有独立意义的人**
- 学生是**独立于教师头脑之外、不以教师意志为转移的客观存在**
- 学生是**学习的主体**（主体性＝**主观能动性**：独立性、主动性、创造性）
- 学生是**责权的主体**（享有法定权利，也需承担相应责任）

### 人的身心发展规律及教育启示（科目二也考，此处一并掌握）
| 规律 | 含义 | 教育启示 | 反例（选择题陷阱） |
| --- | --- | --- | --- |
| 顺序性 | 由低级到高级、由量变到质变，不可跳跃、不可"盈"而后进 | **循序渐进**，不能"一锅煮""陵节而施" | 拔苗助长、幼小衔接"小学化" |
| 阶段性 | 不同年龄阶段有不同总体特征与主要矛盾 | 不能**混淆阶段**、"成人化"或"幼稚化" | 把中学生当儿童管 / 把小学生当中学生教 |
| 不平衡性 | 同一方面速度不均（**关键期/最佳期**）；不同方面发展不均 | 抓住关键期，适时而教 | 错过关键期就"完全无法补偿"（错） |
| 互补性 | 生理与生理互补、生理与心理互补 | 扬长避短、**长善救失**，残而有为 | — |
| 个别差异性 | 个体之间在水平、结构、方式上不同 | **因材施教**，不搞"一刀切" | "一刀切""一锅煮"主要违背**个别差异性**（2023 下真题） |

### 影响人身心发展的因素（"内发外铄"之争）
| 因素 | 作用 | 代表观点/人物 |
| --- | --- | --- |
| 遗传 | 物质前提，提供可能性；不决定现实性 | 孟子"性善"、"生而知之"、"上智与下愚不移"、高尔顿"遗传决定论"、格塞尔"双生子爬梯实验"（成熟势力说） |
| 环境 | 把可能变为现实，但影响具有**两面性与选择性** | "近朱者赤"、荀子"性恶"、"孟母三迁" |
| 教育（学校教育） | **起主导作用**（有目的、有计划、有组织；由专业人员实施；能控制其他因素） | "教育万能论"（爱尔维修）是夸大 |
| 个体主观能动性 | **决定性因素**，是个体发展的内因 | —— 同等环境影响结果不同，取决于主观能动性（2025 下真题） |
| 智力/非智力因素 | 非智力因素（动机、兴趣、情感、意志、性格）起调节与维持作用 | — |

> **同一环境，不同结果 → 取决于主观能动性**；**"教育万能"错在夸大教育，忽视遗传、环境、能动性**。

## 三、教师观

### 1. 教师角色的转变（4 条）
1. 从"知识的传授者"转变为学生**学习的引导者和学生发展的促进者**（最核心的转变）
2. 从"课程的执行者"转变为**课程的建设者和开发者**
3. 从"教书匠"转变为**教育教学的研究者**（行动研究者）
4. 从"封闭型教师"转变为**社区型的开放教师**（教育资源的整合者、家校社协同者）

### 2. 教师行为的转变（4 组）
| 维度 | 应如何做 |
| --- | --- |
| 师生关系 | 尊重、赞赏、平等对话（不伤害人格尊严） |
| 教学 | 帮助、启发、引导（"授人以渔"），重学法指导 |
| 自我对待 | **经常性的教学反思**（反思是教师成长的核心途径） |
| 同事关系 | 团结协作、资源共享、互相听课评课（不搞"文人相轻"） |

### 3. 教师职业劳动特征（单选常考，用关键词识别）
**复杂性**（任务、对象、内容多样）、**创造性**（因材施教、教学方法不断更新、教育机智）、**示范性**（"桃李不言，下自成蹊"、"身正为范"）、**长期性**（"十年树木，百年树人"、人才滞后效应）、**连续性**与**广延性**（空间上无界、时间上延续）、**主体性**与**间接性**。
> "教育机智"＝教师对突发情况迅速判断、随机应变、化处理的能力，是**创造性**的最高表现。

### 4. 教师专业发展
- **内涵**：教师的专业思想、知识、能力、道德等由不成熟到成熟的发展过程，是**持续终身**的过程。
- **阶段理论**：
  - 福勒 & 布朗：关注**生存** → 关注**情境** → 关注**学生**（成熟标志是**关注学生**）
  - 伯利纳：新手 → 熟练新手 → 胜任型 → 业务精干型 → 专家型
  - 叶澜等：非关注 → 虚拟关注 → 任务关注 → 自我更新关注
- **途径**（2025 下科目二简答真题）：① **观摩和分析优秀教师的教学活动**；② **微格教学**；③ **进行专门训练**；④ **对教学经验的反思**。另可加：终身阅读与专业写作、教育行动研究、同伴互助与专业引领、网络研修、承担公开课与课题研究。
- **波斯纳公式：经验 + 反思 = 成长**（教学反思三阶段：教学前反思 → 教学中反思 → 教学后反思；方法：写反思日记、详案、课后小节、教学案例分析、行动研究、学生反馈）。
- 《中学教师专业标准（试行）》基本理念：**师德为先、学生为本、能力为重、终身学习**。

### 5. "四有"好老师 / 引路人 / 四个相统一
- **四有**好老师：有理想信念、有道德情操、有扎实学识、有仁爱之心。
- **四个引路人**：学生锤炼品格的引路人、学习知识的引路人、创新思维的引路人、奉献祖国的引路人。
- **四个相统一**：坚持教书和育人相统一、言传和身教相统一、潜心问道和关注社会相统一、学术自由和学术规范相统一。

## 四、"以人为本"的完整含义（写作文可直接用的三个层次）
1. 哲学的**人本论**——一切为了人、依靠人、发展人、解放人；
2. 历史唯物主义的**群众史观**——人民群众是历史的创造者；
3. 我国法律与教育实践的**人身权观**——尊重人格尊严、保障合法权益、关爱生命健康。
落到教育：一切为了每一位学生的发展 = **全面 + 全体 + 可持续**的发展。

## 五、材料分析题（第 30 题）满分模板

> **总—分—总**，字数 300—450 字，**理论 + 材料对应**，一条一段，序号化。

```
【首句定性】
（1）答：该教师的做法是（正确/合理/值得肯定/不妥当/违背……）的，符合（违背）了新课改背景下的（教育观/学生观/教师观）要求。（1—2 句）

【分条析理】通常写 4—5 条，每条三句式：
① ×× 观认为，……（理论表述，写出关键词即得分）。（2 分）
   材料中，×× 老师……（引用材料中的具体行为/语言，一句即可）。（2 分）
   这体现了／有利于……（1 分）
② ……

【结尾收束】
综上，我们应当（树立正确的教育观，把学生看作发展的人……），做新时代"四有"好老师。
```

### 判断"该用哪一观"的快速口诀
- 题干问**"教育观/素质教育观"** → 从"面向全体、全面发展、个性发展、创新精神与实践能力、提高国民素质、三维目标/核心素养、自主合作探究、发展性评价、课后实践"里选点。
- 题干问**"学生观"** → 从"发展的人（潜能/规律/过程中的人）、独特的人（完整/差异/与成人不同）、独立意义的人（客观存在/主体/权责主体）"里选点，并常配"因材施教""尊重差异""长善救失"。
- 题干问**"教师观"** → 从"引导者与促进者、课程建设者与开发者、教育教学研究者、社区型开放教师 + 师生尊重赞赏、教学帮助引导、自我反思、同事协作"里选点。
- 题干问**"教育思想/教育观和学生观"** → 两大块都要写，各 2—3 条。

## 六、模块自测（单选，先做再看答案）

1. 某高中只给年级前 50 名开"拔尖班"，其余学生照常上课。从素质教育内涵看，该做法主要违背了（ ）。
   A. 面向全体学生 B. 促进个性发展 C. 培养创新精神 D. 提高国民素质
2. "学生是学习的主体"体现的学生观要点是（ ）。
   A. 学生是发展的人 B. 学生是独特的人 C. 学生是具有独立意义的人 D. 学生是未完成的人
3. 张老师坚持每学期写 20 篇教学随笔，并根据学生反馈调整教学。这最能体现教师专业发展的途径是（ ）。
   A. 观摩教学 B. 微格教学 C. 教学反思 D. 学历提升
4. 下列说法正确的是（ ）。
   A. 遗传决定人的发展现实性 B. 学校教育在人的发展中起主导作用
   C. 环境对人的影响总是积极的 D. 关键期一旦错过，发展将无法进行
5. 材料：高二物理老师赵老师发现学生怕学"电磁感应"，便把课堂搬进实验室，让学生自己连接线圈、观察电流计指针，再引导归纳规律；对操作慢的小组，他不催促，只提供图卡提示；课后他把这节课的录像回看，发现提问集中在前排，于是下一节课改为抽签发言；他还与化学、数学老师共同设计了"电能计量"跨学科作业。
   问题：请从教师观角度评析赵老师的行为。（14 分）
