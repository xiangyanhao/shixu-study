## 第二部分：逻辑思维能力

### 一、概念
- **内涵与外延**；概念间关系：
  | 关系 | 图示 | 例 |
  | --- | --- | --- |
  | 全同 | A=B | "北京""中华人民共和国首都" |
  | 属种（包含） | A⊃B | "学生"与"高中生" |
  | 交叉 | 部分重合 | "教师"与"党员" |
  | 矛盾 | 非此即彼，无第三 | "及格/不及格" |
  | 反对（对立） | 有第三 | "黑/白"（还有灰） |
  | 全异 | 无重合 | "苹果/桌子" |
- **限制与概括**：加限定词缩小外延（学生→中学生→高一学生）＝限制；反之＝概括。
- 真题型：**"水果—苹果—红富士"式的三级包含关系**，选项必须**同向且逐层真包含**。

### 二、判断（命题）
| 类型 | 形式 | 真假规则 |
| --- | --- | --- |
| 联言 | p 且 q | 全真才真，一假即假 |
| 选言（相容） | p 或 q | 全假才假；**否定一支必肯定另一支（否定肯定式，有效）** |
| 选言（不相容） | 要么 p 要么 q | 必有一真一真不相容 |
| 充分条件假言 | 如果 p，那么 q | **只有"前真后假"为假**；**有效推理：肯定前件→肯定后件；否定后件→否定前件（逆否等价）**；肯后、否前均无效 |
| 必要条件假言 | 只有 p，才 q | 等价于"如果 q，那么 p"；**有效：否定前件→否定后件；肯定后件→肯定前件** |
| 充要条件 | 当且仅当 | 同真同假 |
| 全称 | 所有 S 都是 P | 与特称否定矛盾 |
| 特称 | 有的 S 是 P | 一真即真 |
| 模态 | 必然/可能 | **"不必然 p"＝"可能非 p"；"不可能 p"＝"必然非 p"** |

**对当方阵（必背）**：
- 全称肯定（A）与特称否定（O）**矛盾**；全称否定（E）与特称肯定（I）**矛盾**（一真一假）。
- A 与 E **反对**（可同假，不可同真）；I 与 O **下反对**（可同真，不可同假）。
- A→I、E→O（差等：全称真则特称真；特称假则全称假）。
- 真题："所有猫都怕水"为假 → 必真："有的猫不怕水"。

### 三、推理
1. **三段论**：大前提＋小前提→结论；中项至少周延一次；两个否定前提推不出结论；前提有一个是否定的，结论必否定。
   例：所有教师都需终身学习（M→P），李老师是教师（S→M），所以李老师需终身学习（S→P）。
2. **必要条件／充分条件链**：题干"只有……才……""除非……否则不……"→ **转化为"如果 q 那么 p"**再推。
   "除非 A，否则不 B" ＝ "只有 A，才 B" ＝ "如果 B，那么 A"。
3. **假言选言推理（二难）**。
4. **排序/配对题解法（28 题常客）**：先列**表格**（人×职业×收入），从"最确定的条件"入手填死，再用不等式与"最值"缩小；**代入排除法**最快——把选项代回条件验证。
5. **数字推理（29 题常客）**：
   - 一阶/二阶等差：1,5,11,19,29 → 差 4,6,8,10（二阶等差）
   - 等比与倍数、平方数列（1,4,9,16,25）、立方、斐波那契（前两项相加）
   - **对应规律题**（如 1=5、2=8、3=11、4=?、5=17 → 观察 f(n)＝3n+2 → 4=14）
   - 分组、隔项、图形数（对角和、中心数＝四周和）
   - 解题动作：**先算相邻差**，再算比值，再看平方立方，最后看隔项/分组。
6. **论证类（削弱/加强/前提/结论）**：
   - 削弱＝切断"论据→论点"的联系（举反例、指出他因、样本不具代表性、混淆因果）；
   - 加强＝补充论据、建立联系、排除他因；
   - 必要前提＝"否定代入后论证即崩塌"的那一项；
   - 常见逻辑错误：**偷换概念、以偏概全、诉诸无知、诉诸权威、循环论证、因果倒置、非黑即白、类比不当、滑坡论证**。
