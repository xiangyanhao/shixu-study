**背诵优先级**：★★★★★（与"三观"并列，是主观题的两大稳定来源）

## 一、《中小学教师职业道德规范》（2008 年修订）——必须一字不差

| 条目 | 定位（单选题的"最"字题） | 关键内容（材料分析题得分点） |
| --- | --- | --- |
| **爱国守法** | 教师职业的**基本要求** | 热爱祖国，拥护党，贯彻教育方针，遵守教育法律法规，依法履行教师职责权利；**不得有违背党和国家方针政策的言行** |
| **爱岗敬业** | 教师职业的**本质要求** | 忠诚于人民教育事业，志存高远，勤恳敬业，甘为人梯，乐于奉献；**对工作高度负责，认真备课上课，认真批改作业，认真辅导学生。不得敷衍塞责** |
| **关爱学生** | **师德的灵魂** | 关心爱护全体学生，尊重学生人格，**平等公正对待学生**；对学生严慈相济，做学生良师益友；**保护学生安全，关心学生健康，维护学生权益**；**不讽刺、挖苦、歧视学生，不体罚或变相体罚学生** |
| **教书育人** | 教师的**天职 / 根本任务（道德规范的核心）** | 遵循教育规律，实施素质教育；**循循善诱，诲人不倦，因材施教**；培养学生良好品行，激发学生创新精神，促进学生全面发展；**不以分数作为评价学生的唯一标准** |
| **为人师表** | 教师职业的**内在要求**；师德**区别于其他职业道德的显著标志** | 坚守高尚情操，知荣明耻，**严于律己，以身作则**；衣着得体，语言规范，举止文明；**关心集体，团结协作，尊重同事，尊重家长**；作风正派，廉洁奉公；**自觉抵制有偿家教，不利用职务之便谋取私利** |
| **终身学习** | 教师专业成长的**不竭动力 / 时代发展教师的新要求** | 崇尚科学精神，树立终身学习理念，拓宽知识视野，更新知识结构；**潜心钻研业务，勇于探索创新，不断提高专业素养和教育教学水平** |

**记忆口诀**：**"三爱两人一终身"**（爱国守法、爱岗敬业、关爱学生 + 教书育人、为人师表 + 终身学习）。

## 二、《新时代中小学教师职业行为十项准则》（教师〔2018〕16 号）——建议通读原文

| 准则 | 核心禁止性要求（选择题常给情境让你对号入座） |
| --- | --- |
| 1 坚定政治方向 | 不得在教育教学活动中及其他场合有损害党中央权威、违背党的路线方针政策的言行 |
| 2 自觉爱国守法 | 不得损害国家利益、社会公共利益，或违背社会公序良俗 |
| 3 传播优秀文化 | 不得通过课堂、论坛、讲座、信息网络及其他渠道发表、转发错误观点，或编造散布虚假信息、不良信息 |
| 4 潜心教书育人 | **不得违反教学纪律，敷衍教学，或擅自从事影响教育教学本职工作的兼职兼薪行为** |
| 5 关心爱护学生 | 严格要求学生，**反对以粗暴的方式、言语对待学生**；**不得歧视、侮辱学生，严禁虐待、伤害学生** |
| 6 加强安全防范 | **增强安全意识，防范风险**；在教育教学活动中遇突发事件、面临危险时，**不顾学生安危，擅离职守、自行逃离**属违规 |
| 7 坚持言行雅正 | 为人师表，以身作则，举止文明，作风正派，自重自爱；**不得与学生发生任何不正当关系，严禁任何形式的猥亵、性骚扰行为** |
| 8 遵循公平原则 | **不得在招生、考试、推优、保送及绩效考核、岗位聘用、职称评聘、评优评奖等工作中徇私舞弊、弄虚作假** |
| 9 秉持诚实正直 | 言行一致，表里如一；**不得抄袭剽窃、篡改侵吞他人学术成果，或滥用学术资源和学术影响** |
| 10 规范从教行为 | 勤勉敬业，乐于奉献，**不得索要、收受学生及家长财物或参加由学生及家长付费的宴请、旅游、娱乐休闲等活动，不得向学生推销图书报刊、教辅材料、社会保险或利用家长资源谋取私利** |

配套《中小学教师违反职业道德行为处理办法（2018 年修订）》：
处理种类＝**批评教育、诫勉谈话、责令检查、通报批评**以及**处分（警告、记过、降低岗位等级或撤职、开除）**，并可**取消相关资格、撤销教师资格**。
> 注意："**限制从业**"与"**撤销教师资格**"针对师德失范情节严重者；处理由**学校（事业单位工作人员）或主管部门**按权限作出。

## 三、教师职业道德的其他高频考点

### 1. 范畴（四组）
- **教师义务**：不由个人选择、以奉献为特征。
- **教师良心**：内在的自律机制（行为前指导、行为中监督、行为后评价）。
- **教师公正**：**平等对待、赏罚分明**，是师德的重要标志（"公平原则"）。
- **教师荣誉**：社会对教师道德行为的客观评价与自我意识统一。

### 2. 范畴层次：教师道德认识、情感、意志、信念、行为（品德结构在教育者身上的体现）

### 3. 师德建设的政策表述（可直接用于作文与材料分析）
- **师德是评价教师队伍素质的第一标准**（"第一标准"是选择题高频）。
- 坚持"**教育、宣传、培养、保护、激励、考核**"六个环节，健全师德建设长效机制。
- "**四有**"好老师、"**四个引路人**"、"**四个相统一**"（见 01 文件）。
- "**经师**"与"**人师**"相统一；"**教书**"和"**育人**"相统一。
- 《教育强国建设规划纲要》《教育发展"十五五"规划》持续强调"**立德树人**""**师德师风**""**教师心理健康支持体系与减负**"。

### 4. 传统师德名言（作文可引用）
| 名言 | 出处/含义 |
| --- | --- |
| "学高为师，身正为范" | 陶行知（金陵大学附中校训，后成南京师范大学校训）——为人师表 |
| "千教万教，教人求真；千学万学，学做真人" | 陶行知——教书育人 |
| "捧着一颗心来，不带半根草去" | 陶行知——爱岗敬业、奉献 |
| "爱生如己，教生如子，待生如友" | 现代师德格言——关爱学生 |
| "师者，所以传道受业解惑也" | 韩愈《师说》——教书育人的整体使命 |
| "其身正，不令而行；其身不正，虽令不从" | 《论语》——示范性 |
| "教学相长" | 《礼记·学记》——师生关系与终身学习 |

## 五、自测

1. 教师职业道德区别于其他职业道德的显著标志是（ ）。
   A. 爱岗敬业 B. 为人师表 C. 教书育人 D. 终身学习
2. 师德的灵魂是（ ）。A. 关爱学生 B. 爱国守法 C. 终身学习 D. 为人师表
3. 王老师在寒假办补习班，把自己班上的学生招来收费上课。其主要违背了（ ）。
   A. 教书育人 B. 关爱学生 C. 为人师表 D. 爱国守法
4. 李老师每次批改作业都写一句针对性评语，还根据作业反映的问题调整下一节课的讲解重点。这最能体现（ ）。
   A. 终身学习 B. 教书育人 C. 爱国守法 D. 关爱学生
5. 依据《新时代中小学教师职业行为十项准则》，教师在突发事件、面临危险时不顾学生安危自行逃离，违背的是（ ）。
   A. 坚持言行雅正 B. 加强安全防范 C. 遵循公平原则 D. 规范从教行为
