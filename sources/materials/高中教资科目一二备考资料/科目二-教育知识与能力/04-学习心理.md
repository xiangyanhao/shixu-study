# 科目二 04 · 学习心理（**分值最重的心理学板块**）

> 覆盖：学习理论（行为—认知—建构—人本）、学习动机、学习迁移、知识、技能、学习策略、问题解决与创造性。
> 辨析题与材料分析题的"半壁江山"出自这里。

---

## 一、学习的实质与类型

- **学习**：个体在特定情境下由于**练习或经验**而产生的**行为或行为潜能**的**相对持久**的变化。（关键词：非本能、相对持久、行为潜能也可）
- **加涅的学习结果分类（5 类）**：**言语信息、智慧技能、认知策略、动作技能、态度**。（"学习结果的分类"→ 加涅；"学习层次的分类"→ 加涅八层：信号—刺激反应—连锁—言语联想—辨别—概念—规则—问题解决）
- **奥苏伯尔的两个维度**：
  - 按**进行方式**：**接受学习 vs 发现学习**；
  - 按**与认知结构的关系**：**有意义学习 vs 机械学习**；
  - **有意义学习的实质**：符号所代表的新知识与认知结构中**已有的适当观念**建立**实质性（非字面）和非人为（合理）**的联系；
  - **条件**：① 材料有**逻辑意义**；② 学习者有**有意义学习的心向**；③ 认知结构中有**适当的观念**可以利用；
  - **先行组织者策略**（"引导性材料"，比学习任务抽象、概括、综合，为新旧知识架桥）——**高频单选**。
- **知识学习类型（按复杂度）**：**符号学习**（表征学习，如"狗"字、地图）→ **概念学习**（共同关键特征，如"力"）→ **命题学习**（句子/关系，如"圆的直径是半径的两倍"）。
- **概念掌握方式**：**概念形成**（低龄、从大量例子归纳）与**概念同化**（有语言与经验基础，用定义方式；奥苏伯尔，课堂主要方式）。

> **必背辨析**："**发现学习一定优于接受学习**"→ **错误**。① 二者没有绝对优劣，标准是**是否建立有意义联系、是否与学习任务及学生特点匹配**；② 接受学习可以是**有意义的**（系统讲授+心向），发现学习也可能是**机械**的（盲目尝试）；③ 发现学习费时、对教师与学生要求高，接受学习能在短时内传递大量系统知识；④ 教学中应**结合使用**：低年级/探究性内容多用发现，高年级/系统知识多用有意义接受。

## 二、四大学习理论（**表格必须滚瓜烂熟**）

### 1. 行为主义（外部行为，S—R）

| 人物 | 实验/著作 | 核心规律/观点 | 教育启示 |
|---|---|---|---|
| **桑代克**（教育心理学之父，1903《教育心理学》；**尝试—错误说/联结试误说**） | **猫开笼取食**（饿猫迷箱） | 学习是**试误**形成 S—R 联结；**三大学习定律**：**准备律**（事先有准备则联结满足）、**练习律**（应用则增强/不使用则减弱，**分功能练习与单纯练习**）、**效果律**（满意则联结加强，烦恼则削弱——**最重要**） | 允许试误、及时反馈、避免单纯机械重复 |
| **巴甫洛夫**（经典性条件作用） | 狗唾液分泌 | **获得与消退、自发恢复、刺激泛化与分化**；第一信号系统（具体刺激，人与动物共有）、第二信号系统（**语词**，人类特有） | "一朝被蛇咬十年怕井绳"=**泛化**；区分"abc"与"xyz"=分化；教学语言要准确，避免泛化误解 |
| **华生**（行为主义创始人，1913《行为主义者眼中的心理学》） | 小阿尔伯特实验 | 环境决定论、"刺激—反应"、拒绝研究意识 | 重视环境与训练；但也导致机械 |
| **斯金纳**（**操作性条件作用/强化理论**） | **白鼠压杆（斯金纳箱）**，《有机体的行为》 | 学习是**反应后果（强化）改变行为概率**的过程；**强化（正/负）增加行为；惩罚与消退减少行为**；**塑造（连续趋近）**；**行为塑造的关键在于强化的安排（强化程式）**：连续强化 vs 间隔强化（**固定间隔最稳定**？常考：**变化间隔/比率抗消退最强——固定比率**易停，**变化比率**最抗消退） | **程序教学**（小步子、自定步调、即时反馈、低错误率）；**普莱马克原理（祖母法则：用高频活动强化低频活动）**；行为矫正 |
| **班杜拉**（**社会学习理论/观察学习**，兼行为与认知） | **波波玩偶实验（BoBo doll）** | 学习可通过**观察**发生（**替代性学习**，不必亲自尝试）；四过程：**注意—保持—动作再现—动机**；强化三类：**直接强化、替代性强化、自我强化**；**自我效能感**四来源：**成败经验（最重要）、替代经验、言语劝说、情绪唤醒** | 教师示范、榜样、积极归因训练 |
| **苛勒**（**完形—顿悟说**，格式塔，**对偶学习/认知学习**先驱） | **黑猩猩取香蕉（叠箱/接杆）** | 学习是**顿悟**（对情境**整体关系**的突然理解），不是试误；原有认知结构改组=**完形** | 呈现问题整体、启发"关系"、给思考时间 |
| **托尔曼** | 白鼠迷宫，**认知地图** | **目的行为主义/符号学习**；**潜伏学习**证明学习不等于强化（无强化也形成认知地图，只是不表现） | 学习有目的性、认知结构重要 |

### 2. 认知主义（内部认知结构）

| 人物 | 理论 | 要点 |
|---|---|---|
| **布鲁纳** | **认知—结构说 / 发现学习** | 学习的实质是**主动形成认知结构**；过程：**获得—转化—评价**三阶段；教学四原则（动机、结构、序列、强化）；**学科基本结构**；**螺旋式课程**；**发现学习**的价值：智慧潜力、内在动机、发现法、记忆保持 |
| **奥苏伯尔** | **有意义接受学习 / 先行组织者** | **首要行为（同化）理论**：新知识由**类属学习（下位学习：相关类属/派生类属）**、**总括学习（上位学习）**、**并列结合学习**三种方式获得；**"假如让我把全部教育心理学仅仅归结为一条原理的话——影响学习的唯一最重要的因素就是学生已经知道了什么，要探明这一点并据此进行教学"**（**名言必考**） |
| **信息加工理论** | 加涅、希利厄德 | 学习信息加工模式：**感受器（感觉登记，<2 秒）→ 短时记忆（工作记忆，容量 7±2，保持 5—20 秒，复述）→ 长时记忆（容量无限，编码：语义/表象）→ 反应器**；**注意**是控制过程；**元认知**是调控过程 |

### 3. 建构主义（**新课程改革的理论背景**）
- **知识观**：知识不是对现实的准确表征，只是**一种解释、一种假设**，会随认识发展而不断被修正；知识**不能照搬**，需学生自己建构。
- **学习观**：学习不是教师传递、学生被动接收，而是**学生主动建构**（**主动建构性、社会互动性、情境性**）。
- **学生观**：学生**不是空着脑袋进教室**，教学不能从经验出发，要**在学生原有经验的基础上"生长"出新知识**。
- **教学观**：教学是"引导—发现—交流"，创设情境与协作；主要模式：**支架式教学、随机通达教学、抛锚式教学（锚定式=以真实问题为"锚"）、认知学徒制**。
> 辨析："建构主义否认知识的客观性，因此什么都可以"→ 片面（强调相对性与情境性，但承认知识的适用性，不是主观任意）。

### 4. 人本主义（**罗杰斯、马斯洛**）
- **有意义学习（人本主义）**：以**"全人"**发展为旨归，学习是**涉及情感与个人整体（知情合一）**的、"心智与手并用"的学习；与"无意义学习"（只增长知识、不增长心理与人格的"死学习"）相对；
- **学习的条件**：**逻辑有意义 + 学习者以"有意义心向"参与**；
- **促进学习的条件**：**真诚一致（真实、接受、信任）**、**无条件积极关注（心理安全与心理自由）**、**共情理解**；
- **非指导性教学**（以学生为中心，教师是**"学习的促进者/资源、伙伴"**）；
- **"学会学习"与"变化之学习"**（罗杰斯认为唯一对行为有重大影响的学习，是"发现自我、发现知识"的学习，即学会如何学习、适应变化的学习）；
- **人本主义学习理论**强调**自我实现**、**需要层次**（马斯洛）：缺失需要（生理、安全、归属与爱、尊重）与成长需要（认知、审美、自我实现）；**低级需要基本满足是高级需要出现的前提，但越高级越不易满足**。

## 三、学习动机（**简答 + 材料分析双料高频**）

### 1. 分类
- **内部动机 vs 外部动机**（来源）；
- **奥苏伯尔成就动机的三方面（必考）**：**认知内驱力**（内部，寻求理解，**最重要、最稳定**）、**自我提高内驱力**（外部，地位与自尊）、**附属内驱力**（外部，长者/同伴的赞许，**儿童早期最突出**）。
- **主导性动机与辅助性动机**；高尚与低级。

### 2. 主要理论
| 理论 | 代表 | 要点 |
|---|---|---|
| **需要层次理论** | 马斯洛 | 生理→安全→归属与爱→尊重→认知→审美→自我实现；**缺失性需要与成长性需要**；**"学习需要的满足要以安全、归属与尊重需要的基本满足为前提"**（教育启示：先给心理安全） |
| **成败归因理论** | **韦纳**（三维度六因素） | 三维度：**控制点（内部/外部）、稳定性、可变（可控）性**；六因素：**能力、努力、任务难度、运气、身心状态、外界环境**；**努力是唯一内部、可控、不稳定**的归因。**归因训练**：引导学生把失败归因于**努力不足**（而非能力不足），以免产生**习得性无助** |
| **自我效能感理论** | **班杜拉** | 指个体对自己**能否成功完成某一成就行为的主观判断**；影响：活动选择、努力程度、坚持性、情绪；四来源（成败经验最重要）；**结果期待 vs 效能期待** |
| **成就动机理论** | **阿特金森** | 力求成功（倾向 50% 难度任务）vs 避免失败（倾向极易或极难）；教育：对力求成功者给新异、有难度任务与竞争情境；对避免失败者减少竞赛失败后果、给予更多肯定 |
| **成败能力观/习得性无助** | **塞利格曼** | 经历**失败且不可控**后形成的"无论怎样努力也无法改变结果"的**绝望感、动机、认知、情绪缺陷**；干预：归因训练 + 创设成功体验 |
| **动机与效率关系** | **耶克斯—多德森定律（倒 U 型）** | 动机强度与学习效率呈**倒 U 型曲线**，**中等强度动机效率最高**；且**最佳动机水平随任务性质而变**：**任务越难，最佳动机水平越低；任务越易，最佳动机水平越高**；**考试焦虑偏高者，考前降低动机强度反而更好** |

### 3. 学习动机的培养与激发（**简答必备，两套动宾搭配**）
**培养（长期、内在生成）**
① 了解和满足学生的需要，促使学习需要的产生；② 重视**立志教育**，进行**世界观与理想教育**；③ 正确开展**学习结果的评价**，认真搞好**学习活动**；④ 通过**学习活动**的反馈、表扬与批评，及时**强化**学生的动机；⑤ 培养学生**良好的自我效能感与归因方式**。
**激发（即时、外部唤起）**
① 创设**问题情境**，实施**启发式教学**；② 明确学习的**目的与意义**，激发**求知欲**；③ 正确指导**结果归因**，促使学生保持高昂的学习热情；④ 充分利用**反馈与奖励**的激励作用（**内外结合、以内在动机为主**）；⑤ 合理设置**课堂吸引力与作业难度**（**成就动机适宜、任务难度"跳一跳摘桃子"**）；⑥ 针对学生**个别差异**因材施教，分层次要求。
> 辨析高频：**"为提高学习积极性，奖励越多越好"→ 错误**：过度外部奖励会**削弱内在动机（"德西效应"：外部奖励可能侵蚀内在动机）**，应奖励"努力与进步"、以精神奖励为主。

## 四、学习迁移（**必考辨析**）

| 标准 | 类型 |
|---|---|
| 效果 | **正迁移（促进）**｜**负迁移（干扰）**｜零迁移 |
| 方向 | **顺向迁移（前→后）**｜**逆向迁移（后→前）**（如"学了汉语拼音后学习英语，英语又反过来影响拼音"） |
| 内容/抽象水平 | **水平（横向）迁移**（同难度）｜**垂直（纵向）迁移**（上下位）｜**同化性迁移（顺应性）** |
| 认知结构 | **一般（普遍）迁移**｜**具体迁移**；**同化性、顺应性、重组性迁移** |
| 意识水平 | **一般迁移 vs 具体迁移**；**自主性迁移 vs 非自主性迁移** |

**迁移理论（人物对号）**
- **形式训练说**（最古老）：**官能心理学**，心的官能（记忆、思维）可像肌肉一样训练，迁移是**自动的**——"背八股文训练思维"；
- **共同要素说**：**桑代克、武德沃斯**——只有两种学习有**相同成分**才迁移；"形似则迁"；
- **经验类化说（概括说）**：**贾德**（**"水下击靶"实验**）——对经验的**概括**是迁移的根本，"原理概括教学"；
- **关系转换说**：**格式塔·苛勒**（**"小鸡啄米（戳点取食）"实验**）——迁移取决于对**关系（情境整体）**的顿悟；
- **认知结构迁移理论**：**奥苏伯尔**——迁移受原有认知结构的**可利用性、概括与抽象水平、清晰巩固性**影响；
- **产生式迁移理论**：**安德森**——迁移取决于两种任务**产生式（条件—行动）的重叠**；
- **定势与功能固着**：**邓克尔（Duncker）"蜡烛问题"**＝功能固着；**定势（心向）**由先前活动形成的心理准备状态，**既有促进作用也有阻碍作用**（**"思维定势只有消极作用"→ 错误**）。

**促进迁移的教学**：精选材料（**基础学科 + 具有普遍迁移价值的基本概念原理**）；合理编排教材内容（**结构化、一体化、网络化**）；**确立适当的迁移导向**，教给**学习方法**（如阅读方法、解题策略）；**合理安排教学程序**（**由已知到未知、由简单到复杂**，先一般后具体，兼顾纵向衔接与横向联系）；**学习指导的及时性与反馈**；重视**解题思路与元认知培养**。

> 辨析：**"逆向迁移就是负迁移"→ 错误**（方向 vs 效果两个标准）；**"迁移只要有共同要素就能发生"→ 片面**（还需要主体对关系的顿悟、经验概括、认知结构等条件）。

## 五、知识、技能与学习策略

### 1. 知识
- **陈述性知识（"是什么"，概念命题；意识可提取，**外显**）** vs **程序性知识（"怎么做"，动作与智力操作步骤，**内隐、自动化**）**（安德森）；
- **感性知识（知觉、表象）** vs **理性知识（概念、命题）**；
- 知识的**直观**三种：**实物直观、模象直观、言语直观**；
- 知识的**概括**：比较、区分**变式与反例**（"变式"：**改变非本质特征、保持本质特征**，如"直角三角形、钝角三角形"帮助理解"三角形"）——**必考**；
- 遗忘规律：**艾宾浩斯"先快后慢"**（**无意义材料**；有意义的材料遗忘慢）→ **及时复习、分散复习、超额学习（150% 最佳）**；
- 知识保持策略：及时复习、合理分配、**试图回忆与反复阅读结合**、**多样化**、**多感官参与**、**列提纲/图形化/记忆术（谐音、首字、口诀、位置法、联想法、关键词法）**。

### 2. 技能
- **操作（动作）技能**：物质性、外显性、展开性；形成三阶段（**费茨与波斯纳**：**认知（定向）— 联结（模仿与练习）— 自动化**）；
- **心智（智力）技能**：观念性、内潜性、简缩性；**加里培林**五阶段：**活动的定向—物质或物质化—出声的外部言语—无声的外部言语（内部言语）—自动化**；**安德森**：**认知—联结—自动化**；
- **技能与习惯**：技能是通过练习形成的**合乎法则**的活动方式，**习惯**不一定合乎法则（"习惯是自动化了的行为方式，技能是一种活动方式"）。

### 3. 学习策略（**迈克卡（McKeachie）三分类，必背**）
| 大类 | 子策略 |
|---|---|
| **认知策略** | **复述策略**（重复、抄写、画线、**及时复习**）；**精加工策略**（**记忆术：谐音联想法、首字浓缩、位置法、关键词法、口诀**；**做笔记（康奈尔笔记）、提问、生成性学习、联系生活实际、类比、"迁移"、总结**）；**组织策略**（**列提纲、图形：网络关系图/流程图/层级图、系统结构图、表格；PQ4R 中的"框框/纲要"**） |
| **元认知策略** | **计划策略**（设置目标、浏览、设问）、**监控策略**（**自我测检、跟踪注意、考试时监控速度**）、**调节策略**（调整速度、跳过难题、重新阅读）——**"对认知过程的认知与调控"**（弗拉维尔提出"元认知"） |
| **资源管理策略** | **时间管理**（建立时间表、设置目标优先）、**环境管理**（**图书馆、安静处**）、**资源利用**（**教师、同学、参考资料、技术**）、**学业求助（工具性求助 vs 执行性求助）** |

> 单选高频：
> - "**画线/重复朗读**"→ 复述；**"谐音、口诀、关键词法、做笔记、提问"→ 精加工**；**"列提纲、思维导图、归类、表格"→ 组织**；
> - **"考试时先看易题、发现不懂就回读"→ 调节策略**；**"阅读时自我提问'我懂了吗'"→ 监控策略**；**"制定计划表"→ 计划策略**。
> - 学习策略训练原则：**主体性、内化性、特定性、灵活性、产生性、外部支持**六条。

## 六、问题解决与创造性（简答）

### 1. 问题解决
- 特征：**目的性、认知性（思维操作）、序列性（多步骤）**；
- 过程（**四阶段**）：**发现问题—理解（明确）问题—提出假设—检验假设**；
- **影响问题解决的因素（必背 8 条）**：**问题情境**（呈现方式）、**定势（心向）**、**功能固着**、**原型启发**（鲁班发明锯）、**迁移**、**动机与情绪状态**（**中等强度**）、**智力与能力**、**个性特征（性格、认知风格：场独立 vs 场依存）**、**知识数量与组织（专家与新手的差异在于知识的结构化组织）**、**是否有启发式的策略与思维策略**。
- **提高问题解决能力**：合理利用**错误反馈**；训练**思维策略（算法式 vs 启发式：爬山、手段—目的分析、逆向反推）**；**创设问题情境**；**变式练习**；教授**元认知监控**。

### 2. 创造性（**吉尔福特提出"发散思维"是创造性的核心指标**）
- 三阶段：准备—酝酿—豁朗—验证（**华莱士四阶段**）；
- **发散思维三特征：流畅性（数量）、变通性（灵活/种类）、独特性（新颖）**——**必考区分**：
  - "一题多解数量多"→ 流畅性；"从不同角度类型回答"→ 变通性；"想法与众不同"→ 独特性；
- 影响创造性的因素：**认知（智力——中低智商与低创造性有关，高智商不必然高创造性；发散思维）、人格（好奇心、独立性、坚持性、敢于冒风险）、环境（宽松的家庭与学校氛围）、动机（内在动机）**；
- 培养：**创设有利于创造性产生的适宜环境**（**心理安全与心理自由**、接纳非传统、允许出错）；**注重创造性个性的塑造**（保护好奇心、解除对错误的恐惧、鼓励独立性与个性、培养创新动机）；**开设培养创造性的课程、进行创造性思维训练**（**头脑风暴（奥斯本）、扩散思维（"用途"练习）、联想法、六顶思考帽**）。

## 七、本章高频易错 20 条（先做，再回头查表）

| 易错说法 | 判定/正解 |
|---|---|
| 惩罚与负强化都能增加行为 | 惩罚**减少**、负强化（撤销厌恶刺激）**增加** |
| 消退就是不理他，所以一定先变少 | 消退过程中行为**先短暂增多（消退爆发）**再减少，并可能**自发恢复** |
| 强化就是奖励 | 强化按性质分**正强化（呈现愉快刺激）与负强化（撤销厌恶刺激）**，都增加行为概率；惩罚才减少 |
| 桑代克提出"效果律"说明练习最重要 | 效果律（反馈/满意）是最重要，练习律需与效果律结合才有效 |
| 观察学习必须亲自实践 | 观察学习是**替代性**的，不必亲自尝试；但需注意、保持、动作再现、动机四过程 |
| 自我效能感就是自信心 = 结果期待 | 效能期待是"我能不能做到"，结果期待是"做到会怎样" |
| 学习动机越强效率越高 | **倒 U 型**，中等最佳；任务越难最佳动机水平越低 |
| 归因为能力比归因为努力好 | 归因能力（不可控）**易导致习得性无助**；应引导归因**努力** |
| 先行组织者用于复习旧知识 | 用于**在新知识之前**呈现，提供"类属"的**上位引导性材料** |
| 有意义学习只需材料逻辑意义 | 还需**心向 + 原有适当观念**（三条件） |
| 定势只有消极作用 | 双重性（**同化性正、顺应性负**） |
| 功能固着是智力问题 | 是**认知（知识经验）定势**，可通过练习减弱，不是能力缺陷 |
| 迁移只要有共同要素 | 还需**概括、关系顿悟**等；"共同要素说"本身是片面的 |
| 负迁移是逆向迁移 | 标准不同：效果 vs 方向 |
| 练习次数越多技能越高 | 有**高原现象（中期停滞，因结构与方法改组）**，需反馈与方法调整 |
| 习惯就是技能 | 技能须**合乎法则**；习惯可能是不良的自动化行为 |
| 思维导图属于复述策略 | 属于**组织策略** |
| 画线、抄写属于精加工 | 属于**复述策略** |
| 学习策略就是学习方法 | 策略更宽：含**调控（元认知）与资源管理** |
| 高智商必然高创造性 | 智商与创造性在**中低智力水平相关明显，高智力不保证高创造**（"门槛效应"：一般认为智商约 120 以上时两者相关性减弱） |
| 奖励越好，学生越爱学 | 过度外部奖励会削弱内在动机（**德西效应**） |
| 问题解决只靠智力 | 还受**定势、功能固着、动机、情境与知识组织**影响 |

## 八、真题风格演练

**【辨析】**
1. 负强化就是惩罚。
2. 学习迁移是学习中自然发生的，无需专门训练。
3. 所有接受学习都是机械的。
4. 为了鼓励学生，应该把他们所有的成功都归因于能力。

<details><summary>要点</summary>

1. **错误**。负强化是**撤销厌恶刺激以提高行为概率**（如"表现好可免除额外作业"）；惩罚是**呈现厌恶刺激或撤销愉快刺激以降低行为概率**。前者增加、后者减少行为。
2. **错误**。迁移受**共同要素、经验的概括、关系顿悟、原有认知结构**等条件影响；教学中需**精选材料、结构化教材、教给方法、明确迁移导向**才能有效促进，故有"为迁移而教"。
3. **错误**。奥苏伯尔指出**接受学习可以是有意义的**，只要学习者有有意义心向、材料有逻辑意义且能与原有观念建立实质非人为联系；反之发现学习也可能机械。
4. **错误**。把成功归因于能力虽可增强自豪，但学生遇到失败时易归因于"能力不足"（内部、稳定、不可控），产生**习得性无助**。应更多引导学生归因于**努力与方法**（可控），并通过归因训练维持动机。
</details>

**【材料分析（18 分）】**
高一某班学生英语基础差异大。张老师坚持"每单元先做一张词汇小测，成绩好的贴表扬卡"。半个学期后他发现：一些"贴过卡"的同学不再主动读课外英语，怕"这次考不好会被同学笑话"；而王强连续三次不及格后说"我就是没有学语言的脑子，再努力也没用"，上课开始睡觉。张老师后来改用"记录进步幅度、单元目标自选、允许重做、把'错在哪里'写成反思条"等方法，班级气氛明显好转。
问：
(1) 用学习动机相关理论分析张老师前期做法的问题与后期改进的依据；
(2) 提出你可以帮助该班级进一步激发动机的措施。

<details><summary>要点</summary>

**问题**：① 只表扬"成绩好"（**能力/结果导向**），强化的是**自我提高内驱力与附属内驱力**，忽视**认知内驱力**；对能力一般的学生是**贬低性反馈**，破坏**心理安全需要**（马斯洛：安全、归属、尊重是学习需要的前提）。② 外部奖励（贴卡）**侵蚀内在动机（德西效应）**，导致"不再主动读课外英语"；③ 单一比较形成**常模参照的高利害氛围**，促成了**避免失败**型目标（阿特金森）与**习得性无助**（塞利格曼）。④ 王强的言语是典型的**能力归因（内部、稳定、不可控）**，韦纳理论认为这会使期待与努力下降。
**后期依据**：① "记录进步幅度"→ **个体内差异评价/自我参照**，强调努力与进步，形成**正确归因与自我效能感（成败经验）**；② "单元目标自选、允许重做"→ 降低焦虑、给予**心理自由**，营造**掌握目标**结构，把**失败归因于可控**；③ "写反思条"→ **元认知监控与调节策略**，促进方法改进与深层理解；④ 把表扬与努力、策略挂钩→ 维持**内部动机**。
**进一步措施**：创设**适度难度与问题情境**（最近发展区、"跳一跳摘桃子"）；开展**学习目的与兴趣教育**（联系生活、职业情境）；**归因训练与自我效能培养**（成功体验 + 榜样替代经验 + 言语劝说 + 情绪调节）；**多样化反馈与奖励**（**内部为主、外部为辅，奖"努力与策略"，慎用物质与竞争性奖励**）；**减少横向比较与当众公布名次**（呼应《未成年人学校保护规定》第 10 条）；**分层目标与合作学习**（组间同质、组内异质）；**帮助王强建立"小步成功"档案**并做**生涯/价值引导**，逐步把外部动机内化。
</details>
