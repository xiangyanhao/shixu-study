# 科目二 05 · 中学发展心理（高中生身心特征 + 四大心理学家）

> **单选最"送分"也最"丢分"的一章**：皮亚杰、维果茨基、埃里克森、科尔伯格四张表必须做到"年龄/阶段/特征/教育启示"三线同步回忆。

## 一、发展心理学的几个基本问题（辨析）

| 争论 | 两派 | 评析 |
|---|---|---|
| **先天（遗传）与后天（环境）** | 预成论（遗传决定）vs 环境决定论 | 现代观点：**二者交互作用**，遗传提供可能性，环境（教育）使可能变现实，主观能动性起决定作用 |
| **主动性与被动性** | 内发论（**孟子、弗洛伊德、威尔逊（基因）、格塞尔（成熟）、霍尔（"复演说"）**）vs 外铄论（**荀子、洛克（白板）、华生、斯金纳（操作性条件）**） | 内发论强调内部因素；外铄论强调外部塑造。**"白板说、孟母三迁、近朱者赤、出人头地、环境决定"→ 外铄** |
| **连续性与阶段性** | 渐进积累 vs 质变分阶段 | 二者辩证统一：量变中有部分质变，质变后又新量变 |
| **普遍性与特殊性（差异性）** | 同一规律与个体差异 | 教育要**既遵循共同规律又因材施教** |
| **关键期（最佳期）** | 洛伦兹"印刻"→ 迁移到人的发展 | **教育要适时而教、抓关键期**（如 2-3 岁口语、4-5 岁书面语） |
| **发展的稳定与可变** | — | 时代变化导致"少年化/提前成熟"，教育要**了解当代学生实际** |

**主要概念**：发展 = **量变 + 质变**（既有连续也有阶段）；成熟 = **由遗传基因控制的、按生物程序展开的生理与机能准备状态**；个体差异 = **差异性与共同性并存**。

> 高频辨析："**关键期说明错过后无法弥补**"→ 错（增加困难、但可补偿）；"**成熟与学习无关**"→ 错（格塞尔"双生子爬梯实验"：**成熟机制制约学习准备**，未成熟时训练效果差甚至有害）。

## 二、认知发展：皮亚杰（**必背 4 阶段 + 核心概念**）

**核心概念**：**图式**（认知结构/行为模式）→ **同化**（把新刺激纳入已有图式，"量变"）→ **顺应**（改变或重建图式以适应新刺激，"质变"）→ **平衡**（同化与顺应的动态均衡，是**发展的内在动力/决定因素**）。
- 其他：**客体永久性**（约 8-9 月形成，感知运动阶段重要成就）。

| 阶段 | 年龄 | 标志特征 | 典型"不能" |
|---|---|---|---|
| **感知运动阶段** | 0-2 岁 | 靠感觉与动作认识世界；**客体永久性**获得；末出现**因果与表征** | 无符号/语言思维 |
| **前运算阶段** | 2-7 岁 | **泛灵论**（万物有灵）、**自我中心**（**"三山实验"**）、**不可逆**、**不守恒**、**思维刻板（集中化）**、**只能进行象征性（符号）游戏** | 不会守恒、不会逆推 |
| **具体运算阶段** | 7-11 岁（小学） | **获得守恒**（重量、体积、数目）；**可逆**；能**分类、排序（序列化）**；**仍需具体事物支持**，不能处理纯抽象假设 | 抽象命题推理困难 |
| **形式运算阶段** | 11 岁（初高中）以后 | **命题思维**（脱离具体内容的假设—演绎推理）、**组合推理、抽象思维、思维可逆、补偿、比例推理**；出现**"假想观众""个人神话"**（艾尔金德：高中生自我中心的两面） | — |

> 教育启示：教学要**符合学生认知发展阶段**（不宜"过早形式化"）；**认知冲突（不平衡）是教学契机**，应制造"最近发展区"式冲突；重视**活动、同伴交流（去自我中心）**。
> **单选高频**："中学生能理解'若所有 A 是 B'这类纯符号推理"→ **形式运算阶段**；"儿童认为'两排同样多的棋子排长些就更多'"→ **不守恒（前运算）**；"儿童认为娃娃会疼"→ **泛灵论**。

## 三、社会文化理论：维果茨基（**必背**）

1. **文化的内化**：高级心理机能（有意注意、逻辑记忆、抽象思维）**起源于社会交往**，通过**符号（语言、工具）**中介，由**人际（社会层）→ 个体（心理层）**内化。
2. **"最近发展区"（ZPD）**：**现有水平（独立解决问题的水平）** 与 **在成人或更有能力同伴帮助下能达到的水平** 之间的差距。**教学应走在发展的前面**、**"跳一跳摘桃子"**；教学创造最近发展区。
3. **支架式教学（scaffolding，伍德等提出，源自维氏思想）**：搭脚手架→进入情境→独立探索→协作学习→效果评价。
4. **内部语言（私法语言/自我中心言语）**：维果茨基认为儿童的**"自我中心言语"不是无社会性的（与皮亚杰不同），而是向内转化为内部言语、成为思维工具**。
> 辨析："最近发展区就是学生已经会做的水平"→ 错，是**潜在水平与现有水平之间的差距**；"**教学要适应现有水平、不要超前**"→ 片面。

## 四、人格与社会性发展：埃里克森（**8 阶段，中学段必背**）

| 阶段 | 年龄 | 危机（冲突） | 积极品质（美德） |
|---|---|---|---|
| 1 婴儿期 | 0-1.5 | 信任 vs 不信任 | 希望 |
| 2 儿童早期 | 1.5-3 | 自主 vs 羞怯怀疑 | 意志 |
| 3 学前期 | 3-6/7 | 主动 vs 内疚 | 目的 |
| 4 学龄期 | 6/7-12 | **勤奋 vs 自卑** | 能力 |
| 5 **青春期** | **12-18** | **自我同一性 vs 角色混乱** | **忠诚** |
| 6 成年早期 | 18-25 | 亲密 vs 孤独 | 爱 |
| 7 成年期 | 25-65 | 繁殖（生成）vs 停滞 | 关心 |
| 8 成熟期 | 65+ | 自我整合 vs 绝望 | 智慧 |

**高中重点**：**自我同一性（identity）——"我是谁、我要成为什么样的人"**；同一性**四种状态（马西亚）**：**达成、延缓、早闭（闭锁）、扩散**；
- 教育：给予探索时间与角色榜样；避免"同一性早闭"（父母包办）；对**同一性扩散**（无目标、无承诺）者需**生涯辅导与成功体验**；理解高中生的"逆反"与"从众"都是**自我确认**的过程。
> 辨析："埃里克森认为青春期的主要任务是获得勤奋感"→ 错，是**建立自我同一性**（勤奋感属于学龄期 6-12 岁）。

## 五、道德发展（**三套理论对照，必考**）

### 1. 皮亚杰：道德判断从他律到自律（**对偶故事法**）
| 阶段 | 特征 |
|---|---|
| **前道德阶段（0-5 岁）** | 无规则意识，"实然游戏" |
| **他律道德（权威道德）5-8/10 岁** | 规则**外在、绝对、不可改**；按**后果大小**（而非动机）评判；服从权威；"抵罪性惩罚"；**道德实在论** |
| **自律道德（公正道德）10 岁以后** | 规则是**约定、可协商**；按**动机**评判；同伴互助与**"交换性惩罚"/"回报性惩罚"**；道德相对主义、公正观念成熟 |
| （补充）青少年阶段出现"**自律→原则**"的发展，高中生已能有**基于普遍原则**的道德判断 | |

### 2. 科尔伯格：**道德发展阶段论（"三水平六阶段"，"道德两难故事法"，"汉斯·摩根·偷药故事"）**
- **前习俗水平**（0-9 岁，外在标准）：**阶段 1 惩罚与服从定向**（避罚）、**阶段 2 相对功利（工具性目的与交换）定向**（"你帮我我就帮你"）；
- **习俗水平**（9-15 岁/多数青年成人）：**阶段 3 "好孩子"定向（寻求认可、"乖孩子"取向）**、**阶段 4 遵守法规（秩序与法律）定向**；
- **后习俗水平（原则水平）**（少数成人）：**阶段 5 社会契约（法定的但可商量的）定向**、**阶段 6 普遍伦理原则（良心、公正、人的尊严）定向**。
- 判断标准：**看其"理由"而不是"结论"**；发展顺序固定不可跨越、文化普遍；
- 教育：用**道德两难讨论**引发认知冲突，把学生提高到**高一个阶段**（"+1"策略）；培养**公正共同体**。
> 高频单选："因害怕处罚而不说谎"→阶段1；"为得到赞许而做好事"→阶段3；"为维护社会秩序而守法"→阶段4；"法律不合乎多数人利益时可修改"→阶段5；"为救人而违背法律（偷药）"→ 常见于阶段 5/6 讨论。

### 3. 班杜拉：**道德行为的习得靠观察学习与自我调节**（道德认知 ≠ 道德行为，**"知行脱节"是青少年常见现象**；替代强化与自我强化）。

## 六、中学生（高中生）身心发展特征（材料分析背景知识）

### 1. 生理
身体迅速发育至成熟（**第二性征、性成熟**）；**神经系统成熟，兴奋与抑制不平衡改善，但情绪仍易波动**；体脑发展**不同步**（注意"用脑卫生"）。

### 2. 认知（思维）发展
- **抽象逻辑思维占主导，从"经验型"向"理论型"过渡**（高中二年级是关键期/定型期）；
- 思维的**目的性、计划性、调节性**增强；**辩证逻辑思维**开始发展；
- **批判性与独立性增强但仍有片面性与表面性**（易偏激、"为反而反"）；
- **想象力丰富但现实感不足**；**元认知（对思维的思维）显著发展**；
- 注意：有意注意占主导，**注意的分配与转移**趋于成熟；**记忆以意义识记为主，词逻辑思维记忆占主导**。
> **单选**："高中生思维的主要特点是抽象逻辑思维占主导、由经验型向理论型转化"✓；"思维的'成熟期'在青年初期（高中）"✓；"初中生仍以具体形象思维为主要支柱，抽象思维需经验支持"✓。

### 3. 情绪情感（**高中常考"两极性→逐步成熟"双轨**）
- **半成熟、半专制、半束缚、半自由（"半"字特征：过渡性）**；
- 情绪**强烈、波动大（风暴期——霍尔）**，但**内隐性、掩饰性、文饰性增强**（"心里苦但嘴上不说"）；
- 出现**高级社会情感（道德感、理智感、美感）**迅速发展；**心境化、持久化（情绪的稳定性提高）**；
- **逆反心理**的成因：自我意识高涨、独立需要受阻、教育方式不当（**"过分的干涉、过高的要求、过重的负担"**）；
- **考试焦虑、厌学、情感冷漠**为常见适应问题。

### 4. 自我意识与人格
- 出现**"生理自我（8 月前）—社会自我（3 岁—少年期）—心理自我（青年期）"**三阶段（**自我意识发展**）；
- 高中生**强烈关注自己的外貌、风度、内心世界**（"假想观众"），自尊心极强、敏感；
- 性格逐渐定型但仍具可塑性；**气质无好坏**（**多血质灵活但易变；胆汁质冲动有力；黏液质稳重迟缓；抑郁质敏感多疑**——**不能因气质评优劣**，教育要"因气质施教"）。

### 5. 社会性
**同伴关系（友谊质量）影响超过成人**；**从众（规范性社会影响）** 显著；**早恋（异性疏远期→接近年期→恋爱期）** 需引导不压制；**权威观念转变（由对父母绝对服从到尊重但质疑）**。

### 6. 生涯与发展任务
高中阶段是**生涯探索与职业定向的关键期**（**舒伯"探索期"**；**帕森斯特质—因素论三要素：了解自己（特质）—了解职业（因素）—人职匹配**；**霍兰德人格类型（现实型 R、研究型 I、艺术型 A、社会型 S、企业型 E、常规型 C）**）。

## 七、本章易错 15 条

| 易错说法 | 正解 |
|---|---|
| 同化是改变已有认知结构 | 同化是**纳入**，顺应才是**改变/重建** |
| 平衡是发展的结果而非动力 | **追求平衡的内在需要是发展的决定因素** |
| 前运算阶段儿童已掌握守恒 | 守恒在**具体运算**阶段获得 |
| 皮亚杰"三山实验"测的是自我中心 | 对，测 **前运算阶段儿童的自我中心（不可从他人视角看）** |
| 最近发展区是已能独立完成的任务 | 是**现有水平与潜在水平之间的差距** |
| 教学应等孩子成熟后再进行 | 教学**应走在发展前面**（维氏） |
| 维果茨基同意皮亚杰"自我中心言语是无社会性的" | 维氏认为它是**内部言语的前身，是社会文化的产物** |
| 青春期危机是"勤奋对自卑" | 是"**自我同一性对角色混乱**" |
| 同一性早闭是最好状态 | **同一性达成**才是健康状态；早闭=未经探索即承诺（父母包办） |
| 科尔伯格用"对偶故事"研究道德 | 对偶故事＝**皮亚杰**；两难故事＝**科尔伯格** |
| 判断道德水平看结论对不对 | 看**理由（推理）** |
| 他律道德按动机评判 | 他律按**后果**，自律才按**动机** |
| 胆汁质最差、抑郁质最糟 | **气质无好坏**，各有优缺 |
| 逆反心理说明学生品德差 | 是**自我意识发展**的正常表现，须改变教育方式 |
| 高中生已能完全辩证思维 | **开始发展但仍有片面性、表面性** |
