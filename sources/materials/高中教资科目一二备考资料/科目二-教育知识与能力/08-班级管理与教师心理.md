# 科目二 08 · 班级管理与教师心理

> 章节小、性价比高：**班集体三阶段、班主任工作内容与方法、课外活动、教师成长三阶段、教师心理健康与威信**——多为单选与 10 分简答。

---

## 一、班级与班集体（**必背三阶段**）

**班级**是学校进行教育教学工作的**基本单位**（是**行政单位/基层组织**），但**班级 ≠ 班集体**：班集体是班级发展的**高级（理想）阶段**，具备**共同目标、健全组织、良好舆论与班风、丰富活动、成员归属感**。

### 1. 班集体形成的三个阶段（**简答/单选必考**）
| 阶段 | 特征 | 班主任工作重点 |
|---|---|---|
| **① 组建（初创）阶段** | 学生刚组合，**彼此陌生、核心未形成**，靠学校/班主任指令维持；**结构松散、凝聚力弱** | **全面、细致管理**：了解学生（建立档案、家访）；**提出共同目标与努力方向**；选拔使用**积极分子（班干部）**；建立**班级规范与制度（"公约"）**；组织第一次集体活动（**良好开端**） |
| **② 形成（发展/核心形成）阶段** | **骨干（班干部）与核心形成**，集体舆论与班风初步形成，能自主开展活动，但**仍不稳定**、需外部支持 | **培养与依靠积极分子（班干部）**，指导班委会与团队组织；**树立正确舆论与良好班风**；**加强自我教育**，逐步放手；及时强化良好行为，处理冲突 |
| **③ 成熟（巩固/发展）阶段** | 目标一致、**组织结构健全、核心稳定**，**舆论与班风良好、凝聚力强**，学生**自我教育、自制能力强**，能自主设计与开展活动 | **放手与指导并重（"后台指导"）**：把管理权交给学生，指导**自主计划、自主活动、自主评价**；**提出更高要求（"前景教育"）**，防止**"班级中心主义/小团体主义"与"骄傲自满"**，把集体引向**更高社会目标（与社会、国家需要结合）** |

> **班集体教育的核心：培养集体舆论与班风；班风是集体的"风向标"、集体形成的主要标志（重要外在标志）。**
> **班主任工作的中心环节是组织和培养班集体**（注意与"了解和研究学生是前提/首要环节"区分）。

### 2. 班主任工作的内容与方法（**简答高频**）
1. **了解和研究学生（前提和基础/首要环节）**：个体（身心、家庭、学业、交往）+ 群体（班级结构、舆论、非正式群体）；方法：**观察（最基本）、谈话、家访、书面材料（作业、成绩、档案）、问卷与测验、学生操行评定**。
2. **组织和培养班集体（中心环节）**：确定**共同目标**（近、中、远"前景教育"）；**建立班委核心、培养骨干**；**培养正确舆论与良好班风**；**组织开展形式多样的活动**（班会、团队活动、社会实践）；**建立班级制度（"公约"）**。
3. **做好个别学生的教育工作**：**先进生（严格要求、鼓励竞争、防止骄傲、"一把钥匙开一把锁"）**、**后进生（"差生"）**、**问题行为学生**。
4. **协调校内外各种教育力量（"立交桥"）**：协调**任课教师（班主任是核心/牵头人）**、**学校团队组织**、**家庭（家长会是基本形式/家长学校）**、**社会（社区、基地）**；**班主任是班级教育的组织者和协调者**。
5. **操行评定（学期）**：以《中小学生守则》《中学生日常行为规范》为依据，**客观、激励、发展性**（评语要"写实 + 鼓励 + 期望"）。
6. **班主任工作计划与总结**（学期计划、月计划、周计划；**工作总结**）。
7. **协调处理突发事件（班级日常管理）**。
> **后进生转化"六要"（简答）**：① **关心爱护、尊重人格（消除疑忌、建立信任——前提）**；② **培养对学习的兴趣与需要（激发内部动机）**；③ **寻找"闪光点"、依靠积极因素克服消极因素（长善救失）**；④ **反复抓、抓反复（长期性、反复性）**；⑤ **因势利导、因材施教，提出"跳一跳够得着"的阶梯式要求**；⑥ **协调集体力量，发挥同伴、家校作用（在集体中教育）**；⑦ **归因训练与自我效能感培养（避免习得性无助）**。

## 二、课外、校外教育

- **特征（相对课堂教学）**：**自愿性（自主选择参加）、自主性（学生主体）、灵活性（内容形式多样）、实践性、开放性（突破课堂/学校界限）、综合性**；**不是课堂教学的简单延续或附加**（不是"第二课堂"式补课）。
- **组织形式（三种，必背）**：
  | 形式 | 说明 | 例 |
  |---|---|---|
  | **群众性活动** | 人数最多、面向全体 | 报告、集会、讲座、参观、游览、调查、公益劳动、**班团队会** |
  | **小组活动** | **课外活动的基本组织形式（最主要）** | 学科兴趣小组、科技、文艺、体育小组、社团 |
  | **个人活动** | 个人自主 | 独立阅读、实验、创作、小制作 |
- **校外教育机构**：少年宫、青少年活动中心、科技馆、博物馆、营地（研学）等；**学校—家庭—社会"三结合"教育网络**。
- **综合实践活动/研究性学习（新高考必背）**：包括**研究性学习、社区服务（志愿服务）、社会实践（含军训、学农）、劳动技术教育**；现**劳动**单独设课（**每周不少于 1 课时**；**普通高等学校、中小学、职业学校要把劳动教育纳入人才培养全过程**），高中**志愿服务 2 学分、三年不少于 40 小时**；**综合实践活动 8 学分**。
- **课外活动要求（与教学协调、计划性、从学生兴趣与年龄出发、发挥教师专长、保证学生安全与自愿）**。

## 三、教师心理

### 1. 教师的角色与劳动特点（单选/辨析）
- **角色多样性**：**知识传播者（"传道授业解惑"）、行为示范者（榜样）、组织与管理者、父母与朋友（长善救失、关怀）、学生心理保健者、教育研究者、终身学习者、课程开发者与学习者、社区/家庭教育的引导者**。
- **教师劳动的特点（** 6 条，必背**）**：
① **复杂性与创造性**（对象、任务、方法复杂；**创造性体现于：因材施教、"教学有法而无定法"（方法上不断更新）、"教育机智"（随机应变）**）；
② **连续性与广延性**（时间连续、空间广延——**课内外、校内外**）；
③ **长期性与间接性**（"十年树木，百年树人"，效果滞后、通过学生实现）；
④ **主体性与示范性**（"**教育者必须先受教育**"；"**桃李不言，下自成蹊**"；**教师言行是手段**，最鲜明）；
⑤ **方式的复杂性与劳动手段的个性**（"教学风格个性化"）；
⑥ **劳动成果的综合性与社会性**（"集体劳动的产物"——**马卡连柯"教师集体"**）。
> **辨析**："教师劳动主要是个体劳动，成果也属于个人"→ **错**：教育是**集体协作**的产物（"一位学生成长凝结着众多教师的心血"）。

### 2. 教师素养（简答）
① **高尚的师德（教育理想、敬业、仁爱、为人师表）**；② **渊博的知识（本体性知识【学科】+ 条件性知识【教育心理学】+ 实践性知识【经验与策略】+ 文化科学知识【通识】+ 学科前沿与跨学科）**；③ **教学能力（语言表达能力、组织管理与教育能力、** 教学能力【设计、实施、评价】、**反思与研究能力、运用信息技术的能力、交往与合作能力、教育机智与应变能力**）；④ **健康的心理与人格（情绪稳定、乐观看待学生、同理心、意志坚定）**；⑤ **良好的身体（职业体能）**；⑥ **终身学习的意识与能力**。

### 3. 教师的成长与发展（**福勒与布朗、伯林纳，必背**）
| 理论 | 阶段 | 特征 |
|---|---|---|
| **福勒（Fuller）教师关注阶段论** | ① **关注生存**（新教师：在意"别人怎么看我"、管住学生、领导评价）→ ② **关注情境（任务）**（如何上好课、学生成绩、时间与材料）→ ③ **关注学生**（认识到学生差异，因材施教——**成熟的标志**） | **"是否关注学生"是衡量教师是否成熟的重要标志** |
| **伯林纳（Berliner）教师专业成长五阶段** | **新手 → 熟练新手 → 胜任型 → 业务精干型（熟练）→ 专家型** | 专家型教师：知识结构组织化、问题解决有**自动化与捷径**、**教学计划更概括、灵活（按学生反应调整）**、**课后评价更关注学生反应与理解**、**教学效能感强、反思能力强**（波斯纳"经验 + 反思 = 成长"） |
| **叶澜/我国教师专业标准** | **专业理念与师德（"学生为本、师德为先、能力为重、终身学习"）+ 专业知识 + 专业能力**（三个维度、十四项、六十一要点） | 《中学教师专业标准（试行）》（教师〔2012〕1号）**四个基本理念**：师德为先、学生为本、能力为重、终身学习 |

### 4. 教师心理健康与职业倦怠
- **职业倦怠（马斯拉赫 Maslach 三维度，必考）**：**情绪耗竭（最典型/核心，"心累"）+ 去个性化（"对学生冷漠、标签化"）+ 个人成就感低落（"觉得自己没用"）**。
- **成因**：角色冲突与过载、评价与晋升压力、工作自主性低、缺乏社会支持、组织公平感差、人格（完美主义、外控）。
- **调适**：① **合理认知与期望（改变"必须人人满意"的非理性信念，ABC）**；② **目标重构（从"分数"转向"成长"、找回职业意义）**；③ **时间管理与工作分解（控制可控之事）**；④ **社会支持（同伴互助、教研组、导师、心理咨询）**；⑤ **运动、睡眠、正念放松、兴趣转移**；⑥ **专业发展（读书、课题研究、反思日记）提升效能感**；⑦ **学校层面：减轻非教学负担、民主管理、合理评价（"多劳多得、优绩优酬"、不单纯以升学率评价）**。
- **教师威信**：**威信（令人威望 + 信赖）≠ 威严（靠权力、惩罚、距离）**；来源于**品德、才能、知识、教育水平、良好的师生关系、举止与仪表**；**滥用惩罚与当众羞辱会损害威信**。

## 四、班主任工作常用方法与"情境应对"模板

**方法**：**说服、示范、陶冶、锻炼、评价（品德评价法）、奖惩、操行评定、家访、个别谈话、主题班会（**班主任对学生进行教育的主要阵地**）、班级活动、班级制度（公约）、岗位育人（人人有事做）**。
**突发事件处理原则（"** 教育性、客观性、关联性、及时性、连贯性"）**：
**冷静（**先处理情绪，后处理事情**）→ **稳定秩序、确保安全**→ **了解事实（不先定性）**→ **就事论理、因势利导（把"事件"变"教育资源"）**→ **公平处理（对事不对人、不羞辱）**→ **后续跟进（谈心、家访、班级讨论、制度完善）**→ **反思记录**。
> 案例模板（材料分析 18 分）：
> **"判断（该做法符合/违背×××）—依据（班集体阶段/德育原则/教师职业道德/教育法规）—具体分析（材料逐点）—建议（3—5 条可操作：目标、班规、岗位、活动、评价、家校、辅导）。"**

**新高考背景（2026 命题语境）**：**选课走班**下的"教学班 + 行政班"双线管理；**生涯规划指导（选科、志愿填报、综合素质评价）**；**导师制**；**综合素质评价档案**；班主任需**协调任课教师、指导学生自主管理与生涯规划**。

## 五、易错 12 条

| 说法 | 正解 |
|---|---|
| 班级就是班集体 | 班集体是班级发展的高级阶段，有共同目标、核心、舆论、活动 |
| 班主任工作的首要/中心环节是组织班集体 | **首要（前提）= 了解和研究学生**；**中心环节 = 组织和培养班集体** |
| 课外活动是课堂教学的继续（补课） | 是**自愿、自主、灵活**的教育活动，非"第二课堂"补课 |
| 课外活动的基本组织形式是群众性活动 | **小组活动**是基本（最主要）组织形式 |
| 班风是班集体形成的唯一标志 | 是**重要（外在）标志**，还需目标、核心、舆论、活动等 |
| 对后进生要多批评、少表扬 | 应**尊重信任 + 寻找闪光点**，避免"习得性无助" |
| 教师威信来自严格惩罚和高高在上 | 来自**品德、才能、知识与对学生的关爱**；威严 ≠ 威信 |
| 教师劳动成果是个人的 | 具有**协作性与集体性（"教师集体"）** |
| 关注学生成绩的教师就是成熟教师 | **关注学生（差异与需求）**才是成熟标志（福勒第三阶段） |
| 教学反思可有可无 | "经验 + 反思 = 成长"（波斯纳）；校本教研三领域之一是自我反思 |
| 职业倦怠就是身体累 | 含**情绪耗竭、去个性化、成就感低落**三维 |
| 家校沟通就是把家长叫来训话 | 应以**尊重、合作、指导**为原则（家访要"报喜"、有准备、平等） |
| 综合素质评价只看材料真实与否 | 既须**客观真实**，也要**过程性、发展性、可操作**（并服务招生参考） |

## 六、自测

**单选**
1. 班主任工作的中心环节是（ ）A 了解和研究学生 B 组织和培养班集体 C 协调各方面教育力量 D 做好个别学生教育
2. 班集体建设中，"班干部核心形成、正确舆论初步形成"属于（ ）A 组建阶段 B 形成阶段 C 成熟阶段 D 解散阶段
3. 课外活动最基本（主要）的组织形式是（ ）A 个人活动 B 小组活动 C 群众性活动 D 学科活动
4. 衡量教师是否成熟的重要标志是（ ）A 关注生存 B 关注情境 C 关注学生 D 关注教材
5. 教师职业倦怠的核心维度是（ ）A 去个性化 B 情绪耗竭 C 成就感低落 D 人格解体
6. 提出"经验 + 反思 = 成长"的是（ ）A 波斯纳 B 布鲁纳 C 杜威 D 舍恩
7. 教师劳动"桃李不言，下自成蹊"体现的是（ ）A 复杂性 B 示范性 C 长期性 D 创造性

<details>
<summary>答案</summary>
**1 B；2 B；3 B；4 C；5 B；6 A（波斯纳）；7 B**
</details>

**辨析**
1. 班风建设是班主任工作的全部。
2. 只要教师学科知识渊博，就能教好学生。
3. 课外、校外活动可完全由学校安排，学生必须参加。
4. 教师的教学效果主要由其学科知识水平决定。

<details>
<summary>要点</summary>

1. **错误**。班风是班集体形成的重要标志与关键环节，但班主任工作还包括**了解研究学生、组织培养班集体、个别教育（先进生与后进生）、协调校内外教育力量、操行评定、计划与总结**等。
2. **错误**。除本体性（学科）知识外，还需**条件性知识（教育学、心理学、学科教学法）、实践性知识、通识性文化知识**，以及**教学能力、组织能力、语言表达能力、教育机智、师德与学生关爱**。学科知识丰富不等于会教（"茶壶里煮饺子"）。
3. **错误**。课外活动的基本特征是**自愿性、自主性**，学生可按兴趣选择参加；学校应**引导与提供条件**，不能强制（且不得增加过重负担）。
4. **错误/片面**。学科知识只是条件之一；教学效果更取决于**把知识转化为学生可理解的形式（学科教学知识）、对学生的了解与因材施教、组织与管理、反馈与评价、师生关系与动机激发**等。
</details>
