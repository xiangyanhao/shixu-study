# 科目二 09 · 辨析题专项（判断 + 理由 60 条）

> **辨析题 = 4 小题 × 8 分 = 32 分**，是"背了不会写"最严重的一栏。
> 评分结构通常是：**判断（约 2 分）+ 说理（概念界定/依据 约 3 分）+ 展开（分点分析或举例 约 2 分）+ 结论/纠正（1 分）**。
> 只写"对/错"不说理，几乎零分；判断写反但说理到位，仍可拿到大部分"知识分"。

---

## 一、答题四步模板（背下来，考场上直接套）

```
①【判断】该说法正确 / 错误 / 片面（不科学、不完全合理）。
②【界定】×××是指……（先给概念，把评分点"关键词"写出来）；
        ×××是指……（若有对比概念，一并界定）。
③【析理】因为……（规律/原则/理论依据 + 2—3 个分点：
        "一方面……另一方面……"或"第一……第二……第三……"）；
        例："……"（举一个学科/课堂实例，1 句即可，最能拉分）。
④【结论】因此，应当……（把错误命题改写为正确命题，或补充条件）。
```

**四种常见命题套路与破解**
| 套路 | 例 | 破解 |
|---|---|---|
| **绝对化**（"只要…就""一定""唯一""完全""任何"） | "只要发扬优点就能克服缺点" | 一般**错误/片面**：写出正确关系 + **补条件** |
| **偷换概念**（把 A 的定义安在 B 上） | "负强化就是惩罚" | **分别界定 A、B** + 指出差异（结果方向不同） |
| **混淆标准**（不同划分维度互推） | "逆向迁移就是负迁移" | **点明两套划分标准** + 举反例 |
| **半对半错（片面）** | "教学就是上课""德育就是思想品德课" | 先肯定合理部分，再补"还包含…"，落到**"…是…的基本途径/中心环节，但不等于"** |

**必须掌握的 6 组"对撞概念"**（近年反复出）：主导作用 vs 决定作用；形成性 vs 总结性；正/负 vs 顺/逆迁移；惩罚 vs 负强化 vs 消退；他律 vs 自律；直接经验 vs 间接经验。

## 二、60 条高频命题（先自测，再背理由）

> 使用建议：每天 10 条，**遮住右栏口头作答 60 秒**，说不出理由就在错题本记一条。

### A 组｜教育基础知识（1-12）

| # | 命题 | 判断 + 理由要点 |
|---|---|---|
| 1 | 教育随着人类社会的产生而产生，也将随着人类社会的消亡而消亡。 | **正确**。教育具有**永恒性**，是与人类社会共始终的社会现象，这是教育的社会属性之一。 |
| 2 | 教育可以推动生产力发展，所以生产力的发展水平由教育决定。 | **错误**。生产力**制约**教育的规模、速度、结构、内容手段；教育对生产力起**促进（再生产劳动力与科技）**作用，不能颠倒为"决定"。 |
| 3 | 教育具有相对独立性，因此教育与政治经济发展完全同步。 | **错误**。相对独立性表现为**不平衡**：可滞后于也可超前于政治经济发展；"完全同步"否认了不平衡性。 |
| 4 | 有了学校就有了教育。 | **错误**。学校在奴隶社会才产生，原始社会已有教育；教育是**培养人的社会活动**，比学校更古老。 |
| 5 | 动物的"教"与"学"证明教育起源于本能。 | **错误**。这是**生物起源说（利托尔诺、沛西·能）**的主张，其根本缺陷是**否认教育的目的性、意识性与社会性**；科学解释是**劳动起源说**。 |
| 6 | 现代教育与古代教育的根本区别在于是否设立学校。 | **错误**。学校在古代已存在；根本区别在于**教育与生产劳动是否结合**、是否普及、是否具有科学基础与法制保障。 |
| 7 | 学校教育在人的身心发展中起决定作用。 | **错误**。学校教育起**主导作用**（有目的、有计划、有组织、专门人员、可控）；**个体主观能动性**才是决定性因素，且主导作用须依赖家庭、社会配合。 |
| 8 | 遗传素质差异是造成人与人之间差别的主要原因。 | **错误**。遗传只提供**物质前提与可能性**，不能决定现实发展；差别主要由**环境、教育与主观能动性**共同作用形成。 |
| 9 | "关键期"一旦错过，发展就无法再弥补。 | **错误**。关键期体现发展的**不平衡性**，错过会使发展**更困难、代价更大**，但因**互补性与可塑性**仍可在一定程度上补偿。 |
| 10 | 个体的身心发展差异要求教学循序渐进。 | **错误（张冠李戴）**。个别差异性要求**因材施教**；**顺序性**才要求循序渐进；**不平衡性**要求抓关键期。 |
| 11 | 教育目的是各级各类学校必须遵循的，因而与具体学校无关。 | **错误**。教育目的是**总要求**，须通过**培养目标**在学校层面具体化，二者是一般与个别、整体与部分的关系。 |
| 12 | 杜威主张"教育无目的"，即教育可以没有方向。 | **错误**。杜威反对的是**外在的、强加的、固定的终极目的**，主张教育**内在目的**——"教育即生长、即经验的不断改组改造"。 |

### B 组｜课程（13-22）

| # | 命题 | 判断 + 理由要点 |
|---|---|---|
| 13 | 课程就是教学，二者可以互相替代。 | **错误**。课程是**教育内容及其进程（依据、蓝图）**，教学是**实施课程的基本途径**；有课程不等于已发生教学。 |
| 14 | 教材编写的直接依据是课程计划。 | **错误**。直接依据是**课程标准**（规定学科知识范围、深度、结构及教学基本要求）；课程计划主要解决**学科设置与课时安排**。 |
| 15 | 综合课程就是活动课程。 | **错误**。分科↔综合按**课程组织方式**划分；学科↔活动按**内容固有属性**划分，两组标准不同。 |
| 16 | 选修课程就是校本课程。 | **错误**。选修/必修按**实施要求**划分；国家、地方、校本课程按**设计开发与管理主体**划分，选修课可以是国家课程中的选择性必修或选修模块。 |
| 17 | 隐性课程的效果优于显性课程。 | **片面**。二者功能不同：显性课程达成**预定目标**，隐性课程（校风、师生关系、环境）以**潜移默化**方式影响态度与人格；不可比优劣，应**自觉利用隐性课程**。 |
| 18 | 布鲁纳主张课程应教"永恒不变的古典名著"。 | **错误**。"永恒学科/名著阅读"是**永恒主义（赫钦斯、阿德勒）**；布鲁纳主张**学科基本结构 + 螺旋式课程 + 发现学习**。 |
| 19 | 课程评价就是给学生考试打分。 | **错误**。课程评价是对**课程方案、教材、实施过程与学生发展**的价值判断，包括诊断性、形成性与总结性评价；只测学生是**学业评价**。 |
| 20 | 单元测验属于总结性评价。 | **错误**。教学**过程中**为反馈改进而施测的（随堂提问、单元测验、作业批改）属**形成性评价**；课程/学段结束后的期末与结业考试才是总结性评价。 |
| 21 | 新课改反对接受学习，倡导发现学习。 | **错误**。课改反对的是**过于强调接受学习、死记硬背、机械训练**；接受学习若有意义（学生主动建构）仍是高效途径，应与自主、合作、探究**结合**使用。 |
| 22 | 只要落实三级课程管理，就能增强课程对地方的适应性。 | **片面**。三级管理是**必要条件**，还需地方与学校**课程开发能力、资源、师资培训与审议制度**保障，且国家课程质量仍是根本。 |

### C 组｜教学（23-34）

| # | 命题 | 判断 + 理由要点 |
|---|---|---|
| 23 | 教学就是上课，上课就是教师的讲授。 | **错误**。教学是**教师教与学生学的共同活动**，包括备课、上课、作业、辅导、评价五环节；且本质是**学生特殊认识过程 + 交往过程**，非单向讲授。 |
| 24 | 学生以学习间接经验为主，因而不必重视直接经验。 | **错误**。学习间接经验**必须以个人直接经验为基础**；忽视直接经验会导致"注入式"与理解困难，应"书本 + 实践"结合。 |
| 25 | 知识多了，智力自然就发展了。 | **错误**。知识是发展的**基础**，发展是掌握知识的**条件**，二者**有条件地转化**：须启发思维、传授知识的形成过程、培养迁移与应用能力（"高分低能"）。 |
| 26 | 教师主导作用发挥得越充分，学生主体作用就越小。 | **错误**。二者**辩证统一**：教师主导是为了**激发、组织、引导**学生主体活动；主导得当，主体性越强（"双主"统一）。 |
| 27 | 教学具有教育性，因此传授知识就自动完成了德育。 | **错误**。赫尔巴特"教育性教学"指教学**永远具有德育影响**，但需教师**有意识地**挖掘思想性、结合内容育人；"教书不育人"是可能的。 |
| 28 | 直观教具使用得越多，教学效果越好。 | **错误**。直观是**手段**，须服务于抽象思维与教学目标；过多、无序的直观会分散注意、妨碍概括，且要重视**言语直观**。 |
| 29 | 课堂提问越多，越体现启发性教学。 | **错误**。"满堂问"仍是注入式；启发性关键在于**创设问题情境、激发认知冲突、留出思考空间、引导自主建构**，重质不重量。 |
| 30 | 循序渐进就是不能让学生接触有难度的材料。 | **错误**。循序渐进是按**学科逻辑与学生认知顺序**系统教学；应在**最近发展区**内设置适当难度（赞可夫"高难度"、"跳一跳摘桃子"）。 |
| 31 | 因材施教意味着降低统一要求。 | **错误**。应**统一要求与因材施教相结合**：保底目标一致，路径、速度、层次与评价差异化。 |
| 32 | 班级授课制不利于因材施教，因而应被个别教学取代。 | **错误**。班级授课制**效率高、系统性强、便于集体互助**，是我国教学**基本组织形式**；应通过**分层教学、走班、小组合作、个别辅导**弥补其不足。 |
| 33 | 讲授法就是注入式教学。 | **错误**。讲授法是一种**教学方法**；注入式/启发式是**教学指导思想**。在启发式思想下，讲授可条理清晰、启人思考；反之，处处提问也可能仍是注入式。 |
| 34 | 只要考试成绩好，就说明教师教学效果好。 | **片面**。成绩是评价教学的重要依据之一，但还须看**教学目标达成度、学生能力与品德发展、过程与方法、不同起点的进步幅度（增值评价）**，并注意测验的信度、效度与难度。 |

### D 组｜学习心理（35-46）

| # | 命题 | 判断 + 理由要点 |
|---|---|---|
| 35 | 负强化就是惩罚。 | **错误**。负强化是**撤销厌恶刺激以增强行为**；惩罚是**呈现厌恶刺激（或撤销愉快刺激）以减弱行为**。二者方向与结果均相反。 |
| 36 | 强化、惩罚、消退都能提高学习积极性。 | **错误**。只有强化（正、负）增强行为；惩罚与消退**降低行为概率**，且惩罚有副作用（恐惧、攻击、回避），须慎用。 |
| 37 | 发现学习比接受学习优越。 | **片面**。划分标准是**是否建立有意义联系**，而非方式本身；发现学习利于探究能力与迁移但费时，有意义接受学习效率高、宜于系统知识。应依**任务、内容与学情**结合使用。 |
| 38 | 学习动机越强，学习效率越高。 | **错误**。**耶克斯—多德森定律**：动机与效率呈**倒 U 型**，中等强度最佳；且**任务越难，最佳动机水平越低**。 |
| 39 | 只要经常表扬，学生内部学习动机就会增强。 | **片面**。外部奖励可能**削弱内在动机（"德西效应"）**；表扬应指向**努力、策略与进步**（信息性而非控制性），并逐步内化。 |
| 40 | 把失败归因于能力不足最能激励学生努力。 | **错误**。能力是**内部、稳定、不可控**因素，如此归因易导致**习得性无助**；应引导归因于**努力与方法**（可控、不稳定）。 |
| 41 | 学习迁移是自动发生的，无需教学专门培养。 | **错误**。迁移受**共同要素、经验概括、关系顿悟、原有认知结构**等条件限制，须"为迁移而教"：精选基本觀念原理、结构化教材、教给方法与元认知策略。 |
| 42 | 定势（心向）对问题解决只起阻碍作用。 | **错误**。定势具有**双重性**：在情境不变时起**加速（促进）**作用，在新情境中起**束缚（阻碍）**作用；应训练**思维灵活性、变式与逆向思维**。 |
| 43 | 死记硬背就是机械学习，理解后的接受学习没有意义。 | **错误**。区分**实质（有意义/机械）** 与**方式（接受/发现）**两维；理解后的接受学习正是**有意义接受学习**（奥苏伯尔）。 |
| 44 | 技能与习惯是一回事。 | **错误**。技能是**通过练习形成的、合乎法则的动作方式**（含心智技能）；习惯是自动化了的行为定势，**未必合乎法则**，可能是不良的。 |
| 45 | 学习策略训练就是教给学生具体的学习方法。 | **片面**。学习策略包括**认知策略、元认知策略与资源管理策略**，还须培养**计划、监控、调节**及时间与环境管理、学业求助，并强调**内化与迁移**。 |
| 46 | 高智商必然带来高创造性。 | **错误**。智力与创造性有**"门槛效应"**（中低智力段相关明显，高智力段相关减弱）；创造性还需**发散思维、人格特质（好奇、坚持、独立）、内在动机与宽松环境**。 |

### E 组｜发展心理（47-52）

| # | 命题 | 判断 + 理由要点 |
|---|---|---|
| 47 | 儿童"自我中心"是道德品质差的表现。 | **错误**。前运算阶段"三山实验"所示的自我中心是**认知发展水平**限制（未能去中心化），非品德问题，需通过**角色承担、同伴交往**逐步克服。 |
| 48 | 教学应等儿童相应能力成熟之后再开展。 | **错误**。维果茨基：**教学应走在发展的前面**，创造并牵引"最近发展区"；等待成熟会错失发展良机。 |
| 49 | 学生能独立完成的任务难度，就是其最近发展区。 | **错误**。最近发展区是**现有水平（独立能完成）与潜在水平（在成人或同伴帮助下能完成）之间的差距**。 |
| 50 | 逆反心理是青少年不尊重师长的不良品行。 | **错误**。它是**自我意识高涨、独立需要受阻**的过渡性心理现象，多因干涉过多、要求过高、方法不当；应**尊重、沟通、给选择**而非压制。 |
| 51 | 气质有好坏之分，胆汁质最差。 | **错误**。气质是**先天、无好坏**的典型心理动力特征；各有优缺点（胆汁质热情冲动、抑郁质敏感深刻），应"因气质施教"。 |
| 52 | 学生按科尔伯格理论到达"遵守法规"阶段，其道德发展即已成熟。 | **错误**。习俗水平（含阶段 4）之后还有**后习俗水平（社会契约、普遍伦理原则）**；且道德发展还须落到**道德行为与习惯**。 |

### F 组｜德育、心理与班级（53-60）

| # | 命题 | 判断 + 理由要点 |
|---|---|---|
| 53 | 德育必须从提高学生的道德认识开始。 | **错误**。品德由**知情意行**构成，德育具有**多端性**：可"晓之以理"，也可"动之以情""导之以行""持之以恒"，依学生实际选择开端。 |
| 54 | 只要认识提高了，品德就会稳定形成。 | **错误**。存在**知行脱节**；还需情感体验、意志锻炼与行为练习、强化与习惯养成，并遵循**长期性、反复性**规律。 |
| 55 | 惩罚学生就是实施教育惩戒。 | **错误**。教育惩戒是**学校、教师基于教育目的、以特定措施管理、训诫、矫治的职务行为**（《中小学教育惩戒规则（试行）》），须**合法、正当、适当、与过错程度相适应**，并**禁止体罚、变相体罚、侮辱人格、因成绩惩戒、惩罚全体**。 |
| 56 | 心理健康教育就是心理治疗，主要面向有障碍的学生。 | **错误**。学校心理健康教育**面向全体学生**，以**发展性目标（学会调适、寻求发展）为主**，兼有预防与矫治；心理治疗针对障碍群体并须专业机构。 |
| 57 | 系统脱敏法就是让学生一下子面对最害怕的情境。 | **错误**。那是**冲击（满灌）疗法**；系统脱敏须**建立焦虑等级 + 放松训练 + 由低到高逐级暴露**，利用"放松与焦虑相互抑制"。 |
| 58 | 合理情绪疗法主张通过改变事件来消除不良情绪。 | **错误**。埃利斯 ABC 理论认为**C（情绪与行为后果）由 B（信念）直接引起**，应通过 **D（辩驳）** 改变**不合理信念**（绝对化要求、过分概括、糟糕至极），而非只改变 A。 |
| 59 | 班集体形成了，班主任就可以不再干预。 | **错误**。成熟阶段应**放手但有指导**：提出更高目标（前景教育），防止小团体主义与自满，关注**新成员/新任务与个别学生**，持续巩固集体舆论与班风。 |
| 60 | 教师的威信主要靠严格惩罚和保持距离树立。 | **错误**。威信建立在**高尚品德、扎实学识、教育教学水平、尊重关爱学生、公正待人**之上；靠权力、惩罚与距离获得的是"威严"，反而易疏离并损害威信。 |

## 三、最后 3 天"考场化"训练法

1. **限时**：每题 **≤4 分钟**（含书写），写满 8—10 行；先写判断，再分点。
2. **术语密度**：每题至少出现 **3 个专业名词**（概念 + 提出者 + 规律/原则名称）。
3. **一句话举例**：每题带 1 个课堂实例（"如教师讲'自由落体'先做牛顿管实验再提问"），这是拉开分差的关键。
4. **改写收尾**：错误命题一律以"**应当……**"作结，把"纠错"变成"立论"。
5. **自查**：写完后回看是否有"绝对化副词（一定、只要、完全）"未被质疑——命题人最常用的陷阱就是它。
