# 科目二 03 · 中学教学（**全书最高频，简答+材料分析双料主考点**）

> 一句话定位：**教学 = 教师的教与学生的学的共同活动**；本章必须做到"8 条教学原则、9 条教学规律、5 类教学方法、教学工作的 5 个环节、德育/教学评价"全部能默写并举例。

## 一、教学的意义与任务

- **教学是学校的中心工作**，学校工作必须**以教学为主**；教学是**实现教育目的、实施全面发展教育的基本途径**（"基本途径"≠ 唯一途径，课外活动、社会实践也是途径）。
- 教学的任务：① 基础知识和基本技能（**双基**，首要任务/最基本任务）；② 发展智力、体力和创造才能；③ 培养社会主义品德和审美情趣，奠定科学世界观基础；④ 促进学生身心健康发展、形成良好个性。
> **辨析**："教学就是上课"→ 错，上课（课堂教学）只是教学工作的**一个环节**；"教学是学校唯一的工作"→ 错，是**中心工作/基本途径**。

## 二、教学过程的基本规律（**简答必背 4 条 + 补充 5 条**）

| 规律 | 内涵 | 常考古语/辨析 |
|---|---|---|
| ① **间接经验与直接经验相统一**（间接性规律） | 学生以学习**间接经验**为主；学习间接经验必须以**个人直接经验为基础**；防止只读书本（"注入式/书呆子"）或只重经验（"经验主义"） | "纸上得来终觉浅，绝知此事要躬行"；"你要知道梨子的滋味就要亲口尝一尝"；"读万卷书，行万里路" |
| ② **掌握知识与发展智力相统一**（发展性规律） | 知识是发展的**基础**，发展是掌握知识的**条件**；二者统一于教学活动；防止"智能教育/知识教育"片面化；掌握知识**不必然**发展智力，需**启发式**、活跃思维、传授科学发现过程 | "授人以鱼不如授人以渔""高分低能" |
| ③ **教师主导与学生主体相统一**（双边性规律/双主规律） | 教师起**主导**作用（组织者、引导者），学生是学习的**主体**（主观能动性）；防止"教师中心"（赫尔巴特旧三心）与"儿童中心"（杜威新三心）两个极端 | "师傅领进门，修行在个人"；"不愤不启，不悱不发" |
| ④ **传授知识与思想教育相统一**（教育性规律） | **赫尔巴特**最早提出"**教育性教学**"思想——**教学永远具有教育性**，这是教学的**教育性规律**；知识是思想品德形成的**基础**，思想提高促进学生积极学习知识；二者统一于教学 | "文以载道"；"教书而不育人"错；"只传授知识、不培养品德"错 |

**补充高频规律（简答/辨析也考）**
5. **认知、情感、意志、行为相互作用**（知情意行的统一，德育过程同理）；
6. **智力因素与非智力因素统一**（非智力因素：动机、兴趣、情感、意志、性格——不起认知作用但起**动力、定向、引导、维持、调节**作用）；
7. **传授知识的科学性与思想性统一**；
8. **教师集体主导作用与学生个别差异统一**；
9. **身心交替、动静交替规律**（一节课 45 分钟内注意力呈"课始较高—中段低落—尾段回升"的起伏，即**注意的起伏/警戒递减**）。

## 三、教学原则（**8 条，必背 + 每条形近句 / 反例**）

| 原则 | 贯彻要求 | 正面例 | 反面例/提示 |
|---|---|---|---|
| **1. 科学性与教育性（思想性）相结合** | 保证教学的科学性；结合教学内容进行德育；教师不断提高业务水平与思想觉悟 | "数学课讲祖冲之""通过课文渗透爱国主义" | 只讲知识不管思想（"教书不育人"） |
| **2. 理论联系实际** | 加强书本知识教学；注重在实际运用中培养能力；根据各科特点组织实践、实习；培养学生**分析、解决问题**能力 | "读万卷书，行万里路""上完《赵州桥》去参观本地古桥"；"纸上得来终觉浅" | "两耳不闻窗外事""高分低能" |
| **3. 直观性** | 正确选择直观教具和现代化教学手段；直观与讲解结合；**重视运用语言直观**（最经济、最常用）；防止直观不注意目的 | 实物直观、模象直观（模型、挂图、视频）、**言语直观** | "教具越多越好"→ 错；"直观是为了吸引兴趣而非代替思维" |
| **4. 启发性**（**最高频**） | 加强目的性教育，调动学生**主动性**（前提）；**创设问题情境，善于设疑、激疑、解疑**，引导独立思考；发扬教学民主（师生、生生民主）；调动学生主观能动性；掌握学生**学习实际** | "不愤不启，不悱不发"（孔子最早，世界最早）；"道而弗牵，强而弗抑，开而弗达"（《学记》）；"一个坏教师奉送真理，一个好教师教人发现真理"（第斯多惠） | 注入式；"满堂问"≠ 启发；"教师讲得越多越好" |
| **5. 循序渐进（系统性）** | 按学科逻辑系统与学生**认知发展顺序**（由已知到未知、由简到易、由具体到抽象、由浅入深）；抓住**主要矛盾，突破难点**，使系统教学；循序渐进要**兼顾个别差异**，防止"一刀切" | "学不等""不陵节而施"（《学记》）；"授书不在徒多，但贵精熟"（王守仁）；"读书百遍其义自见"→ 巩固性 | "拔苗助长""陵节而施""杂施而不孙""赶进度" |
| **6. 巩固性** | 在理解基础上巩固；**复习系统安排**（及时复习、分散复习、交叉复习）；在作业与运用中巩固；复习方式多样化 | "学而时习之""温故而知新""拳不离手，曲不离口""遗忘规律→及时复习" | "一天打鱼三天晒网""考前突击" |
| **7. 因材施教** | 针对学生**个别差异**、有的放矢；正视差异、尊重学生；发现学生特长；**因材施教与统一要求结合**（集体教学与个别辅导结合） | "一把钥匙开一把锁""视其所以，观其所由，察其所安"（孔子）；"矮个子挑低篮，高个子调高篮" | "一刀切""一锅煮""千人一律" |
| **8. 量力性（可接受性）** | 了解学生发展水平（**现实发展水平 + 潜在发展水平 / 最近发展区**）；难度适中（"跳一跳，摘桃子"）；**既不能低估也不能高估** | "视其奋力，量力而施"（墨子）；维果茨基"最近发展区"；"教学应走在发展前面" | 教学内容越难越好/越简单越好 |

> **默写口诀**：**"科理直启，循巩因量"**（科学性与思想性、理论联系实际、直观、启发性、循序渐进、巩固性、因材施教、量力性）。
> 也有版本第 9 条"方向性"或"思想性与科学性"合并——**考试按大纲 8 条答**。
> 材料分析万能思路：**判断 → 原则定义 → 材料行为逐句对应 → 反面对比 → 建议**。

## 四、教学方法（按"语言/直观/实践/情景/鉴赏"五类记）

| 类别 | 方法 | 要点 |
|---|---|---|
| 以**语言传递**为主 | **讲授法**（讲述、讲解、讲读、讲演） | 最常用、效率最高，但需配合其他方法；不能"满堂灌" |
|  | **谈话法（问答法/苏格拉底"产婆术"）** | 分**启发式谈话**与**复习性谈话**；要提问有梯度、面向全体 |
|  | **讨论法** | 需一定知识基础；适合高年级；教师是引导者 |
|  | **读书指导法** | 教给阅读方法、培养自学能力 |
| 以**直观感知**为主 | **演示法**（教师做/放） vs **参观法**（现场观察自然社会） | 演示法常与讲授法配合 |
| 以**实际训练**为主 | **练习法**、**实验法**、**实习作业法**、**实践活动法** | 实验法多用于理、化、生；实习作业法强调**实际生产/社会活动**；练习法四要求：明确目的、精选、指导方法、批改反馈 |
| 以**情感（欣赏）陶冶**为主 | **陶冶法（情/环境/人格感化）**、**欣赏教学法** | 陶冶法：**潜移默化**、"让学校的每一面墙壁都会说话"（苏霍姆林斯基） |
| 探究类 | **发现法（布鲁纳）** | 学生自主发现问题、获得结论；费时 |

> **易混辨析**：
> - **演示法 vs 实验法**：教师动手=演示；学生动手=实验。
> - **参观法 vs 实习作业法**：去看=参观；去做（生产/社会实际）=实习。
> - **讲授法 ≠ 注入式**：注入式是**教学指导思想**（把学生当容器）；启发式对立于注入式，讲授法在启发式思想指导下仍是好方法。
> - **"教学有法，无定法，贵在得法"**：选择方法的依据 = 教学目的与任务、课程性质与教材特点、学生年龄特征与知识准备、教师本身条件、时间与设备条件（**5 条，简答**）。

## 五、教学工作的基本环节（**5 个，简答高频**）

1. **备课**（教学的**起始环节/前提**）——**备好课的"三方面"**：钻研教材（课程标准、教科书、参考书）、了解学生（原有基础、兴趣需要、个性特点）、设计教法；**"三种计划"**：学期（年）教学进度计划、单元计划、**课时计划（教案）**（中心/最主要环节是写好**课时计划**）。
2. **上课**（教学工作的**中心环节**，也是**提高教学质量的关键**）——一堂好课的标准（**6 条**）：**目标明确、内容正确、方法得当、结构合理、语言艺术、气氛热烈、板书有序、态度从容、充分发挥教师主观能动性**（常见答法：目标/内容/方法/语言/组织/气氛）。
   - 课的类型：教学课型（新授课、巩固课、技能课、检查课）；**单一课 vs 综合课**。
3. **作业的布置与批改**——要求：分量适宜、难易适度；类型多样（思考、口头、板演、实际操作、作业）；**目的明确、精选**；及时批改、反馈（"有布置必收、有收必改、有改必评"）。
4. **课外作业的辅导（课外辅导）**——是上课的必要补充；包括**答疑、补缺、指导课外作业、培优补差**；**不是上课的重复**，不能加重负担。
5. **学生学业成绩的检查与评定**——常用**考试（口头/笔试/实践）**；衡量测验质量的四大指标：**信度（结果的可靠性、一致性）、效度（测量的有效性、准确性）、难度（通过率/得分率，数值越小越难）、区分度（高分组与低分组的差异程度）**；评定方式：**百分制或等级制 + 评语**。
> 单选高频："衡量测验质量的主要指标"→ **信度、效度、难度、区分度**（**4 个**）；"教学工作的中心环节"→ **上课**；"上好课的先决条件"→ **备课**。

## 六、教学组织形式（单选高频）

| 形式 | 要点 |
|---|---|
| **班级授课制**（**我国基本组织形式**） | 1632 年**夸美纽斯《大教学论》**首先系统论述（**萌芽：昆体良《雄辩术原理》**"分班教学"思想）；特征：**班、课、时（固定）**（"班课时间"三要素）；优点：提高效益、发挥教师主导、**便于学生互相促进**、**按知识系列进行**；缺点：**不利于因材施教**、学生主体性受限、**理论与实践易脱节**、**灵活性差** |
| **个别教学** | 古代（孔子、苏格拉底、西方个别教学）主要形式；最利于因材施教 |
| **设计教学法**（克伯屈，杜威） | 学生自己设计、自己负责、废除教科书与分科，**违背系统传授知识** |
| **道尔顿制**（**柏克赫斯特**） | 废除课堂讲授，学生按**"公约"与"作业表"**自学、教师个别辅导 |
| **特朗普制（灵活课时制）** | **"大班上课（40%）+ 小班研究（20%）+ 个别教学（40%）"** |
| **分组教学**（外部分组/内部分组） | 便于因材施教；缺点是等级划分伤自尊 |
| **走班制/选课制** | 新高考背景下的行政班+教学班并行 |
| **复式教学** | 一个教师在同一教室对**两个及以上年级**用**直接教学与自动作业交替**的方式进行，是班级授课的**特殊形式**（偏远地区） |
| **现场教学/课堂教学之外的教学** | 补充形式 |

> **班级授课制常考选择题**："我国采用班级授课制始于**清代同治元年（1862）京师同文馆**"；"首先系统论述班级授课制——**夸美纽斯《大教学论》（1632）**"。

## 七、教学评价与教学风格

- 按评价基准：**诊断性、形成性、总结性**（见 02 章）；
- 按评价对象：**对教师教学工作评价**（学生学业成绩是评价教师教学效果的重要依据之一，但**不是唯一**依据）；
- 按评价主体：**相对性评价、绝对性评价、个体内差异评价**；
- 当前理念：**发展性评价**（立足过程、促进发展，多元主体、多种方式）。
- **教师教学风格**分析：教学态度、教学能力、教学艺术（**教学机智、幽默语言、"注意学生"能力**——马卡连柯"平行影响"）。

## 八、易错 16 条（辨析题库）

| # | 说法 | 判定与理由 |
|---|---|---|
| 1 | 教学是学校的唯一工作 | 中心/基本途径，还有科研、德育、总务 |
| 2 | 智育就是教学 | 教学是智育的**基本途径**，但智育还可通过课外活动等进行；教学还承担德育、美育等 |
| 3 | 只要传授知识就能发展智力 | 需启发思维、传授科学发现过程，二者**有条件地**转化 |
| 4 | 学生以学习直接经验为主 | 以**间接经验**为主，直接经验为基础 |
| 5 | 学生天职是学好，教师不必关心道德 | 教学具有教育性（赫尔巴特） |
| 6 | 教师主导作用越大越好 | 主导须以**学生主体**为前提，否则成"专制" |
| 7 | 直观教具越多越好 | 直观要服务于抽象思维发展，过多会分散注意、妨碍思维 |
| 8 | 启发性教学就是多提问 | 关键在**激发思维、调动主动性**，"满堂问"仍是注入式 |
| 9 | 循序渐进意味着不能跳跃 | 可以**跨越式**学习（在有条件、有台阶时），关键是**逻辑顺序与系统** |
| 10 | 因材施教可以取消统一要求 | 应**统一要求与因材施教相结合** |
| 11 | 教学越难越好（高难度） | 赞可夫"高难度"要**在"最近发展区"内**，量力而行 |
| 12 | 班级授课制最不利于教学 | 是我国**基本**组织形式，效率高，缺点是不利因材施教 |
| 13 | 复式教学是个别教学的一种 | 是**班级授课制的特殊形式** |
| 14 | 课外辅导就是上课的重复 | 是**必要补充**，不得加重学生负担 |
| 15 | 考试难度越大区分度越高 | 二者不同；难度适中（约 0.5）区分度才最高 |
| 16 | 学业成绩测验的效度高则信度一定高 | **信度是效度的必要不充分条件**：效度高→信度高；信度高→效度不一定高 |

## 九、材料分析题（模板 + 真题风格）

**【给分模板】**
> ①该老师的行为**符合/违背**了×××教学原则（或规律）。②×××原则的含义是……，其贯彻要求是……③材料中，×××老师"……"（引原句/概括），这正是/恰恰不是……④（反面/对比）如果只……就会……。⑤因此我们应当……（2—3 条具体建议）。

**【演练题（18 分）】**
高二物理李老师讲"自由落体"：先演示牛顿管（钱与纸片同时下落）引发疑问，再让学生分组用频闪照片分析数据；对计算慢的小张单独辅导并让其记录数据；最后布置"从教学楼阳台如何估测高度"的作业。有老师说"讲一节课还要做实验、搞分组，太耽误进度，直接讲公式练十遍更实在"。
问：从**教学原则**与**教学过程规律**角度评析李老师的教学。

<details><summary>参考作答（要点）</summary>

1. **符合直观性与启发性统一**。"授人以鱼不如授人以渔"，直观是理解基础，疑问是思维起点：牛顿管演示与设问使学生在观察中产生"为什么"的疑问，教师把提问与设疑结合，调动学生**主动性**，符合启发性原则"创设问题情境、引导独立思考"的要求。
2. **符合理论联系实际原则**。让学生用频闪数据分析、估测楼高，"学以致用"，在实际运用中发展分析解决问题的能力。
3. **符合因材施教原则与量力性原则**。对计算慢的小张单独辅导并安排其力所能及的记录任务，兼顾差异，"有的放矢"；作业难度处于学生"最近发展区"。
4. **符合教师主导与学生主体相统一的规律、掌握知识与发展智力相统一的规律**。李老师在实验中引导学生自己"发现"规律，使知识习得与思维发展同步。
