# 科目二 06 · 中学生心理辅导（心理健康教育）

> **难度低、给分稳**：概念界定 + 方法名称对应 + "教师能做什么"三步走。近年与**《心理健康工作十条措施》**结合命题。

---

## 一、心理健康（**标准定义与标志**）

**心理健康**：个体在外部环境与内部条件相互作用下，心理机能协调、潜能得以发展、能有效适应社会并感到幸福的**持续良好的心理状态**（不是没有心理问题的"绝对状态"，而是**动态、相对**的）。

**常用的判断标准（三要素说/六条说）**：
① **智力正常**（心理健康的**基本条件/重要标志**）；② **情绪良好、稳定而积极**；③ **意志健全、有自制力**；④ **人格完整与稳定**；⑤ **智力与年龄相符、心理行为符合年龄特征**；⑥ **人际关系和谐**；⑦ **社会适应良好（能面对现实）**；⑧ **了解自我、悦纳自我**；⑨ **心理协调统一（认知、情感、意志、行为一致）**；⑩ **无持续心理疾病症状**。

> 高频单选：
> - "**心理健康与否的基准/首要标准**"→ **智力正常**；
> - **区分心理正常与异常的三原则（郭念锋）**：① **主观世界与客观世界的统一性**（有无幻觉、妄想）；② **心理活动的内在协调性**；③ **人格的相对稳定性**。其中①是首要。
> - **正常与异常之间没有不可逾越的鸿沟，是连续体**。

## 二、心理健康教育（学校心理工作的三位一体）

**心理健康教育 = 发展性目标（学会调适、寻求发展）为主体 + 预防性 + 矫治性**
- **学校心理健康教育的总目标**：提高全体学生的**心理素质**，充分发挥潜能，培养乐观、向上的心理品质，促进人格健全发展；
- **具体目标**：使学生**不断正确认识自我、增强调控自我、承受挫折、适应环境的能力**；对**有心理困扰**的学生给予**科学有效的辅导与咨询**；培养**健全人格和良好社会适应能力**；
- **原则（背 8 条）**：科学性与主体性；**面向全体与关注个体差异相结合**；认知实践与体验相统一；**尊重、理解与真诚相结合**；预防、矫治与发展相结合；**合作（学校—家庭—社会）**；**整体发展**；**保密性**。
> 辨析：① "**心理健康教育就是心理治疗/给有毛病的学生治病**"→ 错，**以发展性为目标、面向全体学生**；② "**心理健康教育 = 德育/思想品德教育**"→ 错（联系：互相渗透；区别见下表）。

| 维度 | 德育 | 心理健康教育 |
|---|---|---|
| 目标 | 解决**思想观点、政治方向与道德规范**问题 | 提高**心理素质**、解决心理困扰、发展人格 |
| 内容 | 社会要求的思想/政治/道德规范 | 自我认识、情绪、人际交往、学习心理、生涯等 |
| 方法 | 说服、榜样、陶冶、锻炼、奖惩、品德评价 | **辅导、咨询、行为改变技术、心理测验、团体活动** |
| 师生关系 | 教师是教育者（社会规范代言人） | **强调平等、接纳、共情，以学生为中心** |
| 归类 | 属于**社会意识形态**范畴 | 属于**科学（心理学）**范畴 |

## 三、心理辅导的主要方法（**名称—适用—操作 三栏对应**）

| 方法 | 提出者 | 适用问题 | 关键操作 |
|---|---|---|---|
| **强化法（阳性强化法）** | 斯金纳 | 不良行为矫正、建立新行为 | **奖励符合期望的行为，使其频率增加**；及时、具体、逐步撤销外部强化 |
| **行为契约/代币奖励法** | 行为主义 | 习惯养成、班级行为管理 | 以可兑换"代币（积分）"强化良好行为 |
| **示范法（观察学习）** | 班杜拉 | 恐惧、社交退缩、技能缺乏 | **看他人示范→模仿→强化**（系统示范、参与示范） |
| **系统脱敏法（交互抑制）** | **沃尔普** | **焦虑、恐惧（特定恐怖、考试焦虑）** | ① 建立**焦虑等级**（由低到高）② 学会**放松** ③ 在放松状态下**由低到高逐级想象/接触**，**对抗（抑制）焦虑** |
| **冲击（满灌）疗法** | 马拉塔 | 恐怖、强迫 | **一次性、长时间直接暴露于最令其恐惧的情境**，不撤除（比脱敏快、痛苦大） |
| **厌恶疗法** | 行为主义 | 不良行为（网瘾、酗酒、攻击） | **不良行为 + 不愉快刺激（电击、催吐）配对**，建立条件性厌恶 |
| **代币制/反应代价** | 行为主义 | 课堂纪律 | 良好行为得分、不良行为扣分并可兑换奖励 |
| **理性—情绪疗法（RET/ABC）** | **埃利斯** | **不合理信念引发的焦虑、抑郁、愤怒** | **A 诱发事件 — B 信念（关键）— C 情绪与行为后果**；通过 **D 辩驳** 使不合理信念→**E 新的合理信念/效果**；**不合理信念三特征：绝对化要求（"必须""应该"）、过分概括化（以偏概全）、糟糕至极（"完了"）**；治疗的关键是**改变 B 而不是改变 A** |
| **以人为中心疗法** | **罗杰斯** | 自我认同、人际困扰 | **真诚一致、无条件积极关注、共情（设身处地理解）**——**治疗性关系本身即起效因素** |
| **精神分析/自由联想** | 弗洛伊德 | 潜意识冲突、早期经验 | 自由联想、梦的解析、移情、**宣泄** |
| **森田疗法** | 森田正马 | 疑病、焦虑、强迫 | **"顺其自然、为所当为"**，带着症状生活、行动导向 |
| **肯定性训练（自我肯定/自信训练）** | 沃尔普等 | 不敢拒绝、过度迁就 | 训练**恰当表达自己的情感、需要与权利**（如"破唱片法""负性主张法"） |
| **心理剧/角色扮演/团体辅导** | 雅各布·莫雷诺（心理剧） | 人际、共情 | 在**角色更换与"镜像"中**理解他人；团体是"社会实验室" |

> **单选必考点**：
> - **系统脱敏 = 放松 + 焦虑等级（逐步）**；**冲击疗法 = 直接最强暴露**；两者都是**行为疗法/暴露类**。
> - **合理情绪疗法 = 改变不合理信念（ABC）**；
> - **代币法/强化法/厌恶疗法 = 行为主义（操作性条件）**；
> - **自由联想 = 精神分析**；**"无条件积极关注" = 人本主义**。

## 四、中学生常见心理问题（识别 + 辅导）

### 1. 学业与适应
- **考试焦虑**（表现：心慌、出汗、注意力涣散、"大脑空白"；成因：动机过高/过低、期望压力、准备不足、消极自我暗示）
  **辅导**：① **合理认知（ABC，改变"考砸就完了"的糟糕至极）**；② **系统脱敏/放松训练（呼吸、渐进性肌肉放松、想象）**；③ **充分准备与考试技能训练（时间分配、先易后难）**；④ **降低外部高期望、避免当众公布名次**；⑤ **积极自我暗示与运动、作息**。
- **厌学**（成因：学习目标缺失、师生关系紧张、挫败体验累积、家庭压力）→ 从**成功体验、归因训练、兴趣重构、生涯目标**入手。
- **学习疲劳/过度疲劳**、**网络（手机）依赖**（用**行为契约 + 替代活动 + 家庭配合**）。

### 2. 情绪与意志问题
- **抑郁情绪 vs 抑郁症**（情绪低落 **持续两周以上** 且伴失眠、食欲下降、兴趣丧失、自我评价低、有自伤念头 → 需转介专业机构）；
- **焦虑**、**恐惧（社交恐惧）**、**易怒与情绪失控**；
- **挫折承受力低**（**挫折—攻击、退化、固执、冷漠、幻想、合理化（酸葡萄/甜柠檬）、转移、升华、补偿**等**防御机制**：注意"**酸葡萄**＝否认所得价值（合理化）、"**甜柠檬**＝美化所得"）。
  **提高挫折承受力**：① **正确的挫折认知（认知重评）**；② **目标现实化**；③ **建立社会支持（同伴、师长、家人）**；④ **训练应对与情绪调节（问题解决与情绪调节双路径）**；⑤ **磨炼意志（坚持、自制）**；⑥ **合理宣泄（运动、倾诉、写作、哭泣）**；⑦ **心理防御机制的建设性运用（升华、补偿）**。

### 3. 人际与自我问题
- **人际关系困扰**（宿舍矛盾、被孤立、师生冲突）：**非暴力沟通（观察—感受—需要—请求）、角色采择、共情训练、合作学习**；
- **自卑/自负、自我中心**；
- **早恋**（**引导而不禁止、不公开点名批评、不贴"道德问题"标签**；帮助区分好感、欣赏与责任；与家长沟通避免简单粗暴）；
- **网络沉迷、孤独**。

### 4. 行为问题
**攻击行为**（**用示范、替代强化、代价（反应代价）、认知—情绪重构、问题解决训练**）、**违纪与注意问题（ADHD：注意缺陷、多动、冲动——需医学评估 + 行为管理 + 座位/任务结构调整）**、**抽动、口吃**等。

### 5. 危机与特殊
**自伤、自杀危机（"说出口就是求救信号"：直接询问自杀意念、不离开人、及时通知家长与专业机构）**；**校园欺凌**（见科目二 08 章与科目一法规）。
**危机干预原则**：**及时、就近、稳定情绪、确保安全、多方联动、转介、跟踪回访**。

## 五、学校心理工作的制度与途径（简答）

1. **心理辅导课/心理健康教育课程**（面向全体，主渠道之一）；
2. **个别咨询（面谈、电话、网络）**与**团体辅导**；
3. **学科教学中的渗透**（**主渠道/最重要的途径是各科教学与班级活动**）；
4. **心理咨询室建设**：**个体咨询室、团体活动室、测评室、沙盘/放松室、信箱**，并保证**保密**（例外：涉及自伤伤人、法律要求等需突破保密）；
5. **心理档案与普查**（**新生测评 + 重点学生跟踪**）；
6. **班主任工作与团队活动、实践活动**；
7. **家庭教育指导（家长学校）与社区医教结合**；
8. **转介机制**（学校不能"包治"，超出能力须转介精神卫生机构）。
> **保密原则与例外**：为求助人保密是**基本道德要求**；但当**危及自身/他人生命、未成年人受侵害、法律规定**时**须突破保密**并做最小范围告知。

## 六、与 2026 年政策的结合（**材料分析加分语料，也考单选**）

《进一步加强中小学生心理健康工作十条措施》（教基厅〔2025〕2 号，2025-05-26）要点：
- **动态监测"四份清单"**：**心理健康、家庭经济、行为状况、亲情关系**；
- **用好"两支队伍"**：**班主任、学科教师**队伍的**心理育人能力**，**专职心理教师**（**到校承诺**：2025 年秋季学期开学前完成**配备**）；
- **减轻学生压力**：**压减作业与考试频次、规范办学（禁止超课标、赶进度、唯分数）**、**禁止公布考试排名**；
- **增强体育、劳动、户外与同伴交往**：**每天综合体育活动 2 小时、课间 15 分钟**；
- **培养健康生活方式**：**小学生 10 小时、初中 9 小时、高中 8 小时睡眠**；**手机不得带入课堂**；
- **扩大资源**：**心理援助热线（12355 青少年服务台等）**、**医教结合、家校社协同、专职教师配备达标**。
> 命题角度：**"某校取消公开课表、增加体育大课间、给每生建立心理档案"符合哪些理念** → 答"健康第一、五育并举、发展性心理辅导、全员育人、家校社协同"。

## 七、易错 10 条速判

| 说法 | 判定 |
|---|---|
| 心理健康就是没有心理疾病 | 错，是积极适应与发展的状态 |
| 心理辅导的对象是有心理疾病的学生 | 错，**面向全体学生，以发展性为主** |
| 心理健康教育以药物治疗为主 | 错，以**教育与心理辅导**为主 |
| 心理咨询可以随意告诉别人来访者的情况 | 错，**保密原则**（有例外） |
| 系统脱敏是让学生一下子进入最害怕情境 | 错，**分级 + 放松**；"一下子"是冲击疗法 |
| 合理情绪疗法主张通过改变事件来改变情绪 | 错，**改变对事件的信念（B）** |
| 代币法属于认知疗法 | 错，**行为疗法（强化）** |
| 心理防御机制都是消极的 | 错，**升华、补偿**等具有适应性价值 |
| 抑郁情绪等于抑郁症 | 错，需持续两周以上并影响功能方考虑障碍 |
| 学校应负责诊断和治疗精神障碍 | 错，**学校识别、辅导、转介**，诊断与治疗属医疗机构 |

## 八、演练（材料分析 18 分）

高二女生小林原本成绩中上，进入高三后经常说"我肯定考不上，我让人失望了"，一进考场就手抖、脑子空白，最近常失眠、不愿与同学来往。班主任认为她"就是吃不了苦、想太多"，在班会上点名说"像小林这样不努力的同学要反省"，并要求张贴成绩排名以"激发斗志"。
问：(1) 从心理健康与学习动机角度分析小林的状态与班主任做法；(2) 提出辅导方案。

<details><summary>要点</summary>

**(1) 分析**
- 小林呈现典型的**考试焦虑（伴躯体症状：手抖、脑子空白、失眠）与消极自我评价、社交退缩**；其言语"**肯定考不上**"属**糟糕至极/过分概括化的不合理信念**（ABC 中的 B 是问题核心），同时"**我让人失望了**"显示**附属内驱力主导、外部评价依赖**。
- 依据**耶克斯—多德森定律**，动机强度过高、任务又偏难（高考），效率反而下降，故"逼一逼就更努力"未必有效。
- 班主任做法有三处不当：① **归因与标签化（"吃不了苦"）—无视其真实的情绪与认知困难**，把心理问题**道德化**；② **当众点名批评**损害**自尊与心理安全需要（马斯洛）**，加剧焦虑与退缩；③ **公开排名**增加比较压力，与"**不得公布考试名次、减轻学生压力**"的政策要求（《未成年人学校保护规定》第 10 条、"十条措施"）不符。班主任也**越界承担了咨询师角色**，未做转介。
**(2) 辅导方案（学校—教师—家庭—个人四层）**
① **建立关系与评估**：心理教师**个别咨询（保密）**，评估焦虑程度（可用 SAS/考试焦虑量表）与睡眠、自伤风险；
② **认知层面（合理情绪疗法 ABCDE）**：与"我肯定考不上""让人失望"辩驳，形成"**这次很难，我可以尽力而为之**"的合理信念；结合**归因训练**把结果归因于**努力与方法**（可控）；
③ **行为层面**：**渐进性肌肉放松 + 呼吸训练 + 系统脱敏**（按"平时作业—周练—模拟—高考"设焦虑等级逐级暴露）；**考试技能训练**（时间分配、先易后难、积极自我暗示）；
④ **生活方式**：保障**睡眠 8 小时**、**每天体育锻炼**、减少过度比较与手机使用；
⑤ **环境层面（班主任/科任教师）**：**取消公开排名、改进步与自我参照评价**；给以**具体、过程性的肯定**；**避免当众标签化**；创造**同伴支持（学习小组）**；
⑥ **家庭层面**：与家长沟通**降低过高期望、改善情感表达**，避免"以成绩论爱"；
⑦ **制度层面**：动态更新**"四份清单"**档案，**必要时医教结合转介**精神卫生机构；**跟踪回访**并防止复发。
</details>
