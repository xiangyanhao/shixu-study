## 一、德育的意义、目标与内容

- **德育**：培养学生**正确（科学）的世界观、人生观、价值观**和**良好的道德品质**，**个性全面发展**；学校德育是**全面发展教育中起灵魂与动力作用**的因素。
- 内容（我国）：**世界观、政治立场、道德（社会公德、职业道德、家庭美德）、法纪、心理健康**（大德育概念含**政治、思想、道德、法纪、心理**教育）；《中小学德育工作指南》五个内容方向：**理想信念教育、社会主义核心价值观教育、中华优秀传统文化教育、生态文明教育、心理健康教育**。
- **《新时代公民道德建设实施纲要》**：社会公德、职业道德、家庭美德、**个人品德**。

## 二、德育过程的基本规律（**简答 4 条，必背**）

| 规律 | 含义 | 教育启示 |
|---|---|---|
| **① 德育过程是培养学生知、情、意、行统一发展的过程** | 道德认知（**基础/前提**）、道德情感（**内部动力/催化剂**）、道德意志（**精神力量、克服困难的毅力**）、道德行为（**衡量品德的重要标志/关键**、外显、落实）；**顺序具有"多端性"**（**不一定从"知"开始**，可从情、意、行切入，"一把钥匙开一把锁"） | **晓之以理、动之以情、持之以恒、导之以行**（四句必写）；避免"只重道德认知（说教）"或"知行脱节" |
| **② 德育过程是指导学生主动地进行思想和行为活动的过程（组织学生的活动和交往）** | 活动和交往是德育的**基础/途径**；学生品德在**活动与交往（实践）**中形成，受**教育性活动**引导 | 组织**主题班会、志愿服务、社团、劳动与研学**等实践，避免关起来"讲道理" |
| **③ 德育过程是促进学生思想内部矛盾（学生思想品德形成的内部矛盾）斗争与转化的过程** | 外部教育影响须经学生**自身内化**；学生自身的**认知冲突与自我教育**是动力；教育要**了解学生原有品德水平、激发动机、引导自我斗争** | 长善救失、启发自觉、"把要求变成学生自己的需要" |
| **④ 德育过程是长期的、反复的、逐步提高的过程（学生品德的形成与提高是长期的、反复的、螺旋上升的过程）** | 品德形成非一次完成，**反复**是正常现象（受社会复杂影响、认识不稳定、外部诱因） | **耐心、长期抓、反复抓、抓反复**；避免"一次谈话定终身""贴标签""一棍子打死"；**期望效应**与"二次违纪"时的处理 |

> **高频辨析**：
> - "**德育必须从提高道德认知开始**"→ **错误**（**多端性**：晓之以理、动之以情、持之以恒、导之以行，可根据学生实际选择开端）。
> - "**学生品德一旦形成就不会倒退**"→ 错误（**长期性、反复性**）。
> - "**学生的思想品德是教师教（灌输）出来的**"→ 片面（**在活动与交往中形成，需内部矛盾斗争、自我建构**）。

## 三、德育原则（**8 条，必背 + 每条形近句**）

| 原则 | 内涵 | 贯彻要求 | 常考古语 |
|---|---|---|---|
| **1. 导向性原则** | 德育要有一定**理想方向**，坚持正确政治方向 | 说理疏导、以理服人、以情感人、以行导人 | "培养什么人、怎样培养人、为谁培养人" |
| **2. 疏导原则（循循善诱原则）** | 摆事实、讲道理，**疏通、引导**，提高学生认识，**以理服人、以情感人** | 讲明道理、疏导方针；因势利导、循循善诱；以表扬、激励为主，坚持正面教育 | "大禹治水，在疏不在堵"；"问渠那得清如许，为有源头活水来" |
| **3. 尊重学生与严格要求学生相结合原则** | **既要尊重、信任、理解、爱护学生，又要提出合理要求并坚决执行** | 有理、有据、有度、有序；**尊重是前提（基础），严格要求是保证（核心）**；避免"权威式压制"与"放任式溺爱" | **"爱之愈深，求之愈严"；"要尽量多地要求一个人，也要尽可能地尊重一个人"（马卡连柯）**（**必考名句**） |
| **4. 教育的一致性与连贯性原则** | 学校内部（各科、教师集体）**统一要求**，学校与家庭社会**协调一致**，**保持前后连贯、有系统性** | 教师集体统一、家长社会配合、**防止"5+2=0"（学校 5 天被家庭社会 2 天抵消）** | "同心协力""三结合教育（学校、家庭、社会）" |
| **5. 因材施教原则** | 根据学生**个性、品德差异、年龄特征**，有的放矢 | 了解学生；从实际出发；"一把钥匙开一把锁"；把**集体教育与个别教育结合** | "视其所以，观其所由，察其所安"（孔子）；"一把钥匙开一把锁" |
| **6. 知（认）行统一原则（理论联系实际/言行一致）** | 既要**提高认识（知）**，又要**注重实践（行）**，**言行一致、表里如一** | **晓之以理、动之以情、导之以行**；组织**实践活动**；反对"言语上的巨人、行动上的矮子" | "坐而言不如起而行""读万卷书，行万里路""知行合一（王阳明）" |
| **7. 依靠积极因素，克服消极因素原则（长善救失）** | **一分为二**地看待学生，发扬其**优点（积极因素）**以克服缺点，"因势利导、扬长避短、积极因素转化" | 培养学生**自我认识、自我评价能力**；全面、客观了解学生；靠**正面引导**，"以长救短"；**避免只盯着缺点** | "教育工作的全部，归根结底应当力求实现**长善救失**"（**《学记》**："教也者，长善而救其失者也"） |
| **8. 集体教育与个别教育相结合原则（在集体中、通过集体进行教育）** | **马卡连柯**"平行影响"：先**组织、培养集体**，再通过集体和**平行影响**教育个人；同时注意个别差异 | 建立**集体（班集体）**；开展**集体活动**；把**集体教育与个别教育相结合**；马卡连柯"**平行教育影响**"与"**前景教育**" | **"个人是集体的一种，他可以而且应当为集体而牺牲自己"（马卡连柯）** |

> **口诀**：**"导疏尊一致，因材知行两依靠"**（导向、疏导、尊重与严格、一致与连贯、因材施教、知行统一、长善救失、集体与个别）。
> **名句—原则对应（必考）**：马卡连柯"要求 + 尊重"→ 原则 3；"长善救失"→ 原则 7；"平行影响"→ 原则 8；"一把钥匙开一把锁"→ 因材施教；"5+2=0"→ 一致性与连贯性。

## 四、德育方法（**6 种**）

| 方法 | 内涵/类型 | 要点 |
|---|---|---|
| **1. 说服教育法（说服）** | 通过**摆事实、讲道理**提高认识（**最基本、最常用**；**正面**疏导） | 语言式：**讲解、谈话、讨论、报告、辩论**；事实式：**参观、访问、调查、实例展示**；要求：**针对性、真实性、启发性、情感性**，"言而有据、以理服人"；**不等于空洞说教** |
| **2. 实际锻炼法（锻炼）** | 有目的**组织学生进行各种活动（练习）**以培养品德与行为习惯（**行**） | **常规训练（执行制度、守则）**、**实践作业（值日、劳动、志愿服务）**、**活动（团队活动、课外活动）**；要求**自觉性、长期坚持、指导方法、检查总结** |
| **3. 品德评价法（评价）** | 通过**奖励与惩罚、评比和操行评定**激励或约束 | 奖励（表扬、奖赏）、惩罚（**批评、处分，要慎重、实事求是、说明理由、给予改正机会**）；**评比**（条件公开、民主）**、操行评定（客观、鼓励、发展性）**；**不能滥用、不能以罚代教、不能体罚或侮辱人格** |
| **4. 榜样示范法** | 以**高洁人品、出色事迹、优越环境**作**榜样**，**以情感人、以形导行** | 三类：**教育者（教师以身作则，最直接）**、**榜样人物（伟人、模范、同伴）**、**文艺形象（文学/影视）**；要求**选好榜样、激发敬慕、推动行为，反对"高大全"（贴近学生、可学）**；注意**小学生更喜"教师榜样"、高中生更喜"同伴/名人"** |
| **5. 道德修养法（指导自我教育法）** | **在教师指导下学生自己要求自己、自己改造自己**（**内化、主体性最强**） | **学习典范、反省（"吾日三省吾身"）、自我服务、自我约束、慎独**；要求**提出具体修养任务、教会方法、检查总结** |
| **6. 情感陶冶法（情感感化/陶冶教育）** | 创设**良好情境与教育氛围，以"潜移默化"方式感化、熏陶学生**（**"润物细无声"、无强制性**） | 三类：**人格感化（教师人格、师爱）**、**环境陶冶（校风、班风、"让每一面墙壁都会说话"）**、**艺术陶冶（音乐、美术、文学）**；要求**创设情境、以情动人、避免强制性**；**"对低年级有效"**、**长期性** |
| （7）**心理咨询/辅导**（近年补充） | 解决心理困扰，与德育相互补充 | 区分"心理问题"与"思想品德问题"（**别把心理困扰道德化**） |

> **单选高频**："**德育最基本/最常用的方法是**"→ **说服教育法**；"**我国中学德育工作的基本途径/学校德育的基本途径**"→ **思想政治（道德与法治）课与其他学科教学**（**教学是最基本途径**）。

## 五、德育模式（**4 个，人物—主张**）

| 模式 | 代表 | 核心主张 |
|---|---|---|
| **认知模式** | **皮亚杰、科尔伯格** | 注重**道德认知（判断能力）** 与**道德两难问题讨论**（**"两难讨论法"是其主要教学方法**）；主张"道德教育的目的在于促进**道德判断能力**的发展（**从习俗到后习俗**）" |
| **体谅模式（学会关心）** | **彼得·麦克费尔（McPhail）** | 重在**道德情感**，"**设身处地、体谅他人**"；**把情感（体谅、关心）置于中心**，"学会关心"（**关心自己、他人、自然、人类、事物、观念**）；用**人际情境问题（"生命线"等）**教学 |
| **社会模仿模式（社会学习模式）** | **班杜拉** | 品德是**观察学习的结果**，强调**示范、替代强化、自我强化、行为矫正**；"**通过榜样的示范和奖惩塑造行为**" |
| **价值澄清模式** | **拉斯（Raths）、哈明、西蒙** | 面对价值多元，**不直接灌输"正确答案"**，而是通过"**选择—珍视—行动**"三过程、七步骤（**自由选择、从若干可供中挑选、对后果深思；珍视与喜爱、公开确认；依据选择行动、反复成为生活方式**）帮助学生**澄清自己的价值观**；"**价值观不能给予，只能通过澄清形成**" |
| （补充）**集体教育模式** | **马卡连柯、苏霍姆林斯基** | 通过**集体与在集体中**教育；**"前景教育"**（**远景、中景、近景**，用不断前进的目标激励学生）；苏霍姆林斯基：**"和谐教育""自我教育""美的情感与劳动教育"** |

> 单选："通过道德两难故事讨论提高道德判断能力"→ **认知模式**；"把'关心''体谅'置于中心"→ **体谅模式**；"不灌输，让学生自己选择、珍视、行动"→ **价值澄清模式**；"用榜样和奖惩塑造行为"→ **社会模仿模式**。

## 六、德育途径与学校德育的组织

**途径（"七种"）**
1. **思想政治课与其他学科教学**（**基本途径**）；
2. **社会实践活动/劳动与技术教育/研学实践/志愿服务**；
3. **课外、校外教育活动**；
4. **团队活动（少先队、共青团、学生会）**；
5. **班级日常工作（班主任）**；
6. **学校传统活动（开学典礼、纪念日、仪式）**；
7. **心理健康教育与咨询**（并与家庭、社会协同）。

> 高中语境：**共青团活动**是重要途径；初中：少先队/共青团；小学：少先队。

## 七、品德及其培养

- **品德（道德品质）**：个人依据社会道德准则行动时表现出的**稳定特征与倾向**，是**社会道德在个体身上的体现**；与**道德（社会现象）** 相区别：品德是**个体现象**，具**稳定性、评价性、动机性（与道德需要、动机相联系）**。
- **品德形成的三阶段（** 品德形成的过程，**凯尔曼/一般教材表述**）**：**依从（**从众 + 服从**，表面性、工具性）→ **认同（** 自愿接受他人影响，与社会榜样一致，**半内化**）**→ **内化（**成为自身价值体系的一部分，** 高度稳定、自觉）**。
- **品德的心理结构**：道德认知、情感、意志、行为（见规律①）。
- **培养学生良好品德的方法**：
① **有效的表扬与批评（奖惩）：明确、及时、公正，重精神奖励；**
② **树立榜样（** 示范 + 观察学习、榜样要"可信、可学、有层次"**）；**
③ **开展道德实践（** 在活动与交往中形成，**"知行统一"**）；**
④ **教会自我教育（** 写日记、座右铭、**"吾日三省吾身""慎独"**）；**
⑤ **建立集体（** 舆论、目标、核心层）与**"前景教育"**；**
⑥ **道德认知教育（** 说理 + 两难讨论、明确道德概念与是非标准）；**
⑦ **针对个别差异（** 气质、性格、家庭背景）因材施教。
- **矫正不良品德**：**消除疑忌与对抗情绪（先改善师生关系）；培养对集体的荣誉感和自尊心；反复抓、抓反复（"长期、反复、逐步提高"）；善用"积极因素克服消极因素"；满足合理需要、提供行为替代。**

## 八、易错 12 条

| 说法 | 判定与理由 |
|---|---|
| 德育就是思想品德课的教学 | 德育途径多样，思想品德课只是课程途径之一；**教学是基本途径** |
| 德育必须从"知"开始 | 具有**多端性**，可从情、意、行切入 |
| 只要认知提高了，品德自然形成 | **知行脱节**普遍存在，还需情感、意志、行为练习 |
| 惩罚就是体罚 | 惩罚是**品德评价**手段，**不得体罚或变相体罚、侮辱人格** |
| 表扬越多越好 | 表扬要**实事求是、有度**，过多/不当会贬值、滋生依赖 |
| 榜样要选"高大全"的典型 | 要**贴近学生、真实可学**，否则产生距离与逆反 |
| 陶冶法具有强制性 | 恰恰相反，是**潜移默化、无强制** |
| 价值澄清模式教师不表达任何价值观，等于放任 | 教师是**引导者、示范者**，重在**方法（选择—珍视—行动）** |
| 体谅模式以认知（判断）为核心 | 以**情感（关心、体谅）** 为核心 |
| 学生反复违纪说明教育失败 | 体现德育的**长期性与反复性**，应"反复抓、抓反复" |
| 集体教育是压制个性 | 马卡连柯**"在集体中、通过集体、为了集体"**，且与个别教育结合 |
| 学生心理问题都是思想品德问题 | 需区分心理与品德，**心理辅导与德育各有方法** |
| 家庭教育只是配合，可有可无 | **一致性、连贯性原则**要求学校、家庭、社会协同 |

## 九、演练（材料分析 18 分）

高二（3）班男生小赵聪明但"嘴上道理都懂，做起来就忘"：值日常常溜走、爱给同学起绰号、自习课说话。班主任先是在全班读《中小学生守则》并让他写 3000 字检查；发现无效后，改为①请他担任"班级器材管理员"并在全班表扬其尽责；②与科任教师约定"统一口径：违纪按事先约定的班规处理，不再临时加码"；③请家长每周在校讯本上写一句具体进步，不再只问分数；④每周班会用"如果你是他"讨论真实冲突事件；⑤两个月内小赵仍有 3 次反复，班主任对他说："我们不翻旧账，只看下一次怎么做。"
问：用**德育过程规律与德育原则、方法**分析该班主任的做法。

<details><summary>要点</summary>

1. **规律①知情意行统一（多端性）**："道理都懂、做起来就忘"是**知行脱节**；班主任不再停留于"读守则"（仅说理），而是通过**担任管理员、写进步记录**（**实际锻炼 + 导之以行**）把"知"落到"行"，同时用"表扬、'如果你是他'"**动之以情**，形成闭环。
2. **规律②在活动与交往中形成品德**：安排真实**职责（器材管理）**与**班会讨论**，让学生在**活动、交往、承担角色**中形成责任与尊重他人（比"3000 字检查"更有效）。
3. **规律③思想内部矛盾斗争（自我教育）**：起绰号、自习说话被引导到"**如果你是他**"的换位体验，唤起内部矛盾与自我评价，属于**依靠积极因素克服消极因素 + 指导自我教育**，而非外部灌输。
4. **规律④长期性、反复性**："两个月内反复 3 次"是正常过程，"**不翻旧账、只看下一次**"体现**耐心、反复抓、抓反复**，避免"贴标签"和"一棍子打死"。
5. **原则：依靠积极因素克服消极因素（长善救失）**——"聪明、能尽责"作为**闪光点**被放大；《学记》"教也者，长善而救其失者也"。
6. **原则：尊重学生与严格要求相结合**——**公开表扬、不翻旧账**是尊重；**按事先班规处理、不临时加码**是合理而严格的规范（马卡连柯"尽量多地要求，也尽量多地尊重"）。
7. **原则：教育的一致性与连贯性**——与科任教师"统一口径"、与家长"每周记一句进步"，形成**教师集体、家校一致**的合力，避免"5+2=0"。
8. **原则：因材施教**——根据其特点（讲义气、爱表现、能负责）安排角色，"一把钥匙开一把锁"。
9. **方法：品德评价法（奖励为主、惩罚慎重）**、**实际锻炼法（职责）**、**说服教育（讨论而非宣读）**、**榜样/同伴与集体教育**、**自我修养指导**。
10. **不足与建议**：①"读守则 + 写 3000 字检查"是**单一说理与过度惩罚（可能变相加重负担，违背《中小学教育惩戒规则》第 12 条"超过适当限度的抄写"）**；②应完善**班级制度与集体舆论**（把"起绰号"纳入班规公约、设"尊重"主题班会）；③**跟进强化**：把短期进步固化为习惯，逐步撤销外部奖励（内化）；④注意**心理辅导**：若起绰号、话多有冲动/注意因素，应结合行为契约与个别辅导。
