# 法律法规与政策文件 · 通读全文清单（科目一必备）

> 科目一"教育法律法规"模块 8 道单选（16 分）+ 隐性支撑材料分析题和作文的价值观；科目二"教育方针/课程/德育/教师心理"多处直接引用政策原文。
> 命题有个稳定规律：**法律题的正确项几乎都是"原文改写"，错误项几乎都是"改了主体、改了数字、改了'可以/应当'、颠倒程序顺序"**。
> 所以：**摘要版能帮你得分，只有原文能帮你不出错。** 下面按"是否值得通读"分四档，并给出每篇的读法与用时。

---

## 阅读方法：拿任何一篇法规，只盯五样东西

| 抓手 | 说明 | 典型考法 |
| --- | --- | --- |
| ① 数字 | 几周岁、几日、几年、几课时、百分之几 | 把"15 个工作日"改成"30 日" |
| ② 主体 | 谁来做：父母/学校/教师/县级政府/教育行政部门/公安机关/法院 | 把"县级以上人民政府"换成"学校" |
| ③ 程度副词 | 应当 / 可以 / 不得 / 禁止 / 原则上 | 把"可以"改成"应当" |
| ④ 程序顺序 | 批评教育→教育惩戒→纪律处分→申诉→复核→复议/诉讼 | 打乱顺序 |
| ⑤ 禁止性清单 | "不得有下列行为"整段 | 混进一条"看起来合理"的行为 |
