## 二、这套资料怎么用（重要）

1. **第一轮（理解 + 建框架，约 4—6 周）**
   - 科目二按 01→08 顺序读，每读一节，合上文件默写"这一节的三级标题 + 每条要点的前两个字"，写不出就重读。
   - 科目一先读 01、03（三观一德，占 30%，且是主观题），再读 02（法规），04（文化素养）只当作"睡前读物"零碎看。
2. **第二轮（刷题 + 补漏，约 4 周）**
   - 只做**真题**（近 5—6 次），每套限时。错题进入《错题本与默写模板.md》，按"来源/日期—错因类型—我为什么错—正解关键词—复现记录"五栏记录（错因只用 5 类：概念混淆／记忆缺失／审题失误／方法不会／时间不够）。
   - 科目一的作文必须**动手写满 3 篇**（不是列提纲），每篇严格 1000 字以上、45 分钟内完成。
3. **第三轮（冲刺背诵 + 模考，约 2 周）**
   - 只背三个文件：《科目一-三观一德必背条目》《科目二-高频简答背诵清单》《辨析题专项》。
   - 考前 3 天回到本清单，把《法律法规与政策文件通读清单.md》里"第一梯队"的原文再扫一遍数字和禁止性条款。

## 三、通过线：别把 90 分当安全线

笔试各科**卷面满分 150 分**，成绩公布时换算成**报告分满分 120 分、70 分合格**。换算按当次通过率线性转换，因此**卷面 90 分不等于通过**。

> 经验目标：**科目一卷面 ≥ 100 分，科目二卷面 ≥ 95 分**才比较稳。
> 换算公式（x = 卷面分，A = 当次卷面合格线，y = 报告分）：
> - x < A 时：y = x / A × 70
> - x ≥ A 时：y = 70 + (x − A) / (150 − A) × 50

## 五、备考中最容易翻车的 6 件事

1. 科目一作文没写完 / 不足 1000 字 / 跑题 → 直接掉到 30 分以下，一科就废。
2. 材料分析题只抄材料不写理论，或只写理论不结合材料 → 每题少拿 6—8 分。
3. 辨析题**只判断不说明理由**（或判断错） → 8 分题得 0—2 分。
4. 法规题把"可以"记成"应当"、"5 日"记成"15 日"、"县级"记成"省级"。
5. 简答题写不全点 → 阅卷是**踩点给分**，宁可用口诀列 5 条短句，不要写 2 条长段落。
6. 文化素养（18 分）花 30 小时，写作（50 分）只花 3 小时——投入产出比反了。
