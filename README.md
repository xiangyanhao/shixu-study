# 师序 · 高中信息技术教资学习台

## 启动

需要 Node.js 22 或以上，无须安装 npm 依赖。在本目录执行：

```powershell
npm start
```

打开 http://127.0.0.1:4173 。也可双击 `启动学习台.cmd`，保持服务窗口开启。不要直接双击 `dist/index.html`，资料读取需要 HTTP 服务。

如果PowerShell提示禁止执行npm.ps1，请用 `npm.cmd start`（测试同理使用 `npm.cmd test`）。

## 功能

- 知识资料库：49份原始备考资料、教材章节和课标补充章节，全文搜索、章节目录、已读进度、PDF页码对照。
- 快速自测：选科目、模块、题量与时长，单题确认后查看解析，简答题可选。
- 自主组卷：本地自编题或AI命题，选择难度、简答题和主观题。
- 单科全真模拟：三科各120分钟，完整卷150分。关闭题型后明确标记减量练习。科目三采用微型教材列举的常见结构，不声称是官方固定题型。
- 作答自动保存、固定截止时间、答题卡、标记、跳题、超时交卷；刷新或暂离不重置计时。
- 客观题自动计分；主观题给出参考答案及量规，支持自评与AI估分。
- 错题收集、复习笔记、掌握标记、错题重练、真实记录统计与AI掌握情况分析。
- 资料答疑；有未交卷练习时不提供AI答疑。
- 学习记录备份导出与校验导入。

## 新增课标

已纳入上级目录《信息技术最新版课程标准.pdf》，封面标注《普通高中信息科技课程标准（2017年版2025年修订）·日常修订版》。按12个主题补充知识库，保留PDF原文及PDF页码。涉及课程目标、素养、内容要求、学业质量、教学评价时优先检索此来源；与笔记冲突需明确说明。PDF中学生学业水平考试建议不用于覆盖教资试卷蓝图。图表提取可能丢失布局，应打开PDF核对。

## 模型接入

进入“模型与数据设置”，填写：

1. 模型 URL：例如 `https://你的服务/v1` 或完整 `/chat/completions` 地址。
2. API Key：自己的服务密钥。
3. 模型名称：服务商提供的准确模型ID。

保存后点击“测试连接”。AI按OpenAI兼容的 `POST /chat/completions` 请求，正文包含 `model`、`messages`、`stream:false`，使用 Bearer 鉴权。为兼容服务，不强制专有JSON响应参数，输出在程序中严格校验。

本地启动时如遇CORS可启用“本机代理”；代理只监听127.0.0.1，限制同源浏览器调用，不保存或记录密钥。在线静态部署版直接请求服务，需要服务允许CORS。本机代理不部署到静态托管。

API Key默认仅保留内存；主动勾选后保存在本标签页的sessionStorage。URL与模型名保存在localStorage，学习数据不含Key。浏览器恢复标签页可能恢复会话，请使用“清除 Key”彻底清除。资料、问题、答卷会发给自行配置的服务，可能产生费用。

## 模型职责与来源约束

`AGENTS.md` 说明维护规则，`dist/policies.js` 是每次模型请求实际注入的运行时策略。`dist/core.js` 校验生成题的题量、分值、选项、模块、重复题、资料短引文、主观题量规和评分范围。失败会明确报错，不会悄悄换成本地题。

本地题与AI生成题均为自编模拟，不是真题。主观题成绩为自评/AI估分，不转换官方报告分。题库不提供官方通过预测。已验证接口协议与错误处理；实际模型服务需填写有效凭据后测试。
