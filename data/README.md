此目录保存便携版数据。请保持项目目录可写。

- `study.json`：当前答卷、错题、笔记、已读进度，以及模型URL/名称等非密钥设置。
- `study.previous.json`：上一次成功保存的记录，意外损坏时可在停止服务后复制为 `study.json` 恢复。
- `study.pending.json`：保存过程中的临时文件，正常情况下会自动替换为正式文件。

换电脑时，停止服务，再复制整个项目目录（包含本目录）。新电脑启动后会自动恢复数据，无需使用相同浏览器或端口。
API Key 不写入 study 数据。启用本机加密保存后，Windows DPAPI 密文独立保存在 `.local-secrets/credentials.json`，只由本地代理使用，不回显到页面。该目录不进入便携包和学习备份，新设备需要重新填写。手动迁移时也请排除 `.local-secrets`。首次从旧版本迁移时，先在旧浏览器导出学习备份，再在便携版“模型与数据设置”中导入。
